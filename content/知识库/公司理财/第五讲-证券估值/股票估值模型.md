## 核心考点

**名词解释高频**：DDM股利折现模型（2025多校）、Gordon增长模型（清华/中财）；**计算题**：已知D₁、g、r求P₀（Gordon模型）；已知P₀、D₁、g求r（股权资本成本）；多阶段增长模型分段计算（清华/复旦）。**辨析**：NPVGO模型说明"高增长率不等于高股价"（成长型股票vs价值型股票）；r = D₁/P₀ + g是股权资本成本的直接估算公式（股利增长模型法）。**判断题**：r > g是Gordon模型的必要条件，否则PV→∞；零增长模型是永续年金的直接应用（P = D/r）。

## 概念精讲

### 一、股利折现模型（DDM）基础

**定义**：股票内在价值等于其未来所有预期股利的现值之和。

$$P_0 = \sum_{t=1}^{\infty} \frac{D_t}{(1+r)^t}$$

> **为什么用股利而非利润？** 股东实际获得的是股利（现金流），保留在公司的利润属于公司而非股东；公司金融关注现金流而非账面利润。DDM是永续增长年金的直接应用。

**要求回报率（r）的分解**：对于固定增长股票，可以推导出：

$$r = \frac{D_1}{P_0} + g = \underbrace{\text{股利收益率}}_{\text{Dividend Yield}} + \underbrace{\text{资本利得率}}_{\text{Capital Gains Yield}}$$

> **含义**：持有股票的总回报 = 每年股利收益 + 股价增值。若股利永续以 g 增长，股价也以同等速率 g 增长，资本利得率恰好等于 g。这也是**股权资本成本**的估算公式（股利增长模型法）。

---

### 二、零增长模型（Zero Growth Model）

**假设**：股利永远不增长，每期固定为 D。

$$P_0 = \frac{D}{r}$$

> 这是**永续年金**的直接应用。典型案例：无增长的成熟企业、优先股（固定股利率）。

---

### 三、固定增长模型（Gordon增长模型）

**假设**：股利从 D₁ 开始，以固定增长率 g **永续增长**（严格要求 r > g）。

$$P_0 = \frac{D_1}{r - g} = \frac{D_0(1+g)}{r - g}$$

**决策规则**：P₀ > 市场价格 → 股票被低估，买入；P₀ < 市场价格 → 高估，卖出。

> **r > g 的必要性**：若 g ≥ r，PV趋向无穷，模型无法给出有意义的估值。实践中，长期稳定增长率 g 通常不超过经济增长率（约3-5%），而股权资本成本 r 一般在8-15%之间，故条件通常满足。

**股权资本成本的估算**：已知市场价格P₀、最近股利D₀（或D₁）和预期增长率g，可反推：

$$r = \frac{D_1}{P_0} + g$$

---

### 四、多阶段增长模型（Differential Growth Model）

**适用场景**：成长期企业前期高速增长，之后进入稳定增长阶段。

**两阶段法（常见考法）**：
- 阶段1（t = 1 到 t = T）：超常增长率 g₁（逐期计算每期股利并折现）
- 阶段2（t > T）：稳定增长率 g₂（用Gordon模型计算 t = T 时刻的股价 $P_T$，再折现至今）

$$P_0 = \sum_{t=1}^{T} \frac{D_t}{(1+r)^t} + \frac{P_T}{(1+r)^T}$$

其中 $P_T = \dfrac{D_{T+1}}{r - g_2}$，$D_t = D_0(1+g_1)^t$（超常增长阶段），$D_{T+1} = D_T(1+g_2)$（进入稳定阶段）

> **计算步骤**：①按 g₁ 逐期算出 D₁, D₂, ..., D_T；②用 D_{T+1}=D_T(1+g₂) 算出过渡股利；③计算 P_T = D_{T+1}/(r-g₂)；④对所有 Dt（t=1到T）和 PT 求现值并相加。

---

### 五、NPVGO 模型（增长机会净现值）

**核心思想**：股票价格 = 无增长股价 + 增长机会的现值

$$P_0 = \frac{EPS_1}{r} + NPVGO$$

其中：
- $\dfrac{EPS_1}{r}$：假设公司将全部盈利以股利形式分配（无增长，永续年金）的股价
- **NPVGO**（Net Present Value of Growth Opportunities）：公司再投资于正NPV项目所创造的额外价值

> **关键洞见**：增长本身不一定创造价值——只有**正NPV项目的增长**才有价值。若公司将利润投资于NPV=0的项目（如仅赚取资本成本的项目），增长不改变股价，NPVGO=0。成长型股票（高P/E）的溢价来自市场认可其NPVGO为正。

**留存比例（b）与增长率（g）的关系**：

$$g = b \times ROE$$

其中 b 为留存比率（= 1 - 股利支付率），ROE为权益回报率。

- 若 ROE > r：增加留存（高b）→ g↑ → P₀↑（成长型股票）
- 若 ROE < r：增加留存实际**损害**股东价值（再投资回报低于要求回报）
- 若 ROE = r：留存比率不影响P₀，NPVGO = 0

---

### 六、市场比率法（辅助参考）

| 比率 | 公式 | 含义 |
|------|------|------|
| **市盈率（P/E）** | P₀/EPS₁ | 为每1元盈利愿意支付的价格；高P/E反映高增长预期 |
| **市净率（P/B）** | P₀/账面净资产/股 | 反映市场对公司资产创值能力的评价；P/B > 1时市场认可ROE > r |

> **P/E与Gordon模型的联系**：由 P₀ = D₁/(r-g) 和 D₁ = EPS₁(1-b) 可得：$P/E = \dfrac{1-b}{r-g}$。高增长率 g 和高股利支付率（低b）均推高 P/E。

## 机制逻辑

**为什么资本利得率等于 g（Gordon模型成立时）**：P₀ = D₁/(r-g)，则 P₁ = D₂/(r-g) = D₁(1+g)/(r-g) = P₀(1+g)。股价每年以 g 增长，资本利得率 = (P₁-P₀)/P₀ = g。这解释了为何持有固定增长股票的总回报 = D₁/P₀ + g，且总回报恰好等于要求回报率 r（均衡条件）。

**NPVGO为负时意味着什么**：若公司将盈利再投资于ROE < r的项目，每次投资都会销毁价值（低于要求回报），NPVGO < 0，此时P₀ < EPS/r。公司最好将全部利润分配为股利（b=0）。这是"成长中的价值毁灭"现象。

**多阶段增长模型的本质**：将无法直接套用永续增长公式的不稳定现金流序列，分割为可处理的两段：①逐期折现的有限期现金流；②尾端用Gordon模型处理的永续部分。两段现值之和即为内在价值。

## 比较辨析

| 模型 | 适用条件 | 核心公式 | 局限性 |
|------|---------|---------|--------|
| **零增长模型** | 股利永不增长 | P₀ = D/r | 过于理想化 |
| **Gordon增长模型** | 股利永续固定增长，r > g | P₀ = D₁/(r-g) | 对 r 和 g 极敏感；r≤g时失效 |
| **多阶段增长模型** | 前期高增长+后期稳定增长 | 分段折现+Gordon尾值 | 需估计各阶段参数，较复杂 |
| **NPVGO模型** | 分析增长机会对股价的贡献 | P₀ = EPS₁/r + NPVGO | 需估计NPVGO，依赖再投资假设 |

| 对比项 | 成长型股票（高NPVGO） | 价值型股票（低NPVGO） |
|--------|---------------------|---------------------|
| P/E比率 | 高（市场为增长机会付溢价） | 低（盈利被直接定价） |
| 股利支付率 | 低（留存再投资） | 高（缺少高NPV项目） |
| ROE | ROE > r | ROE ≈ r 或 ROE < r |
| 增长驱动 | 高ROE再投资 | 主要靠分红回报 |

| 对比项 | 股利收益率（D₁/P₀） | 资本利得率（g） |
|--------|-------------------|---------------|
| 来源 | 现金股利 | 股价增值 |
| 在Gordon模型中 | r - g | g |
| 两者之和 | r（要求回报率/股权资本成本） | |

## 答案要点

**DDM股利折现模型（名词解释/简答）**：
- 股利折现模型（DDM）是对股票内在价值的评估方法：股票价值等于其未来所有预期股利的现值之和，公式 P₀ = Σ[Dt/(1+r)^t]
- 核心逻辑：股东实际获得的现金流是股利，用要求回报率（股权资本成本）折现
- 三种特殊情形：①零增长模型 P₀=D/r（永续年金）；②固定增长（Gordon模型）P₀=D₁/(r-g)，严格要求r>g；③多阶段增长：超常增长阶段逐期折现，之后用Gordon模型计算尾值再折现

**Gordon增长模型（名词解释/计算框架）**：
- Gordon增长模型（固定增长DDM）假设股利从D₁起以固定增长率g永续增长，股票内在价值为：P₀ = D₁/(r-g)，其中r为股权要求回报率，g为永续增长率，必须满足r > g
- 股权资本成本的反推：r = D₁/P₀ + g = 股利收益率 + 资本利得率
- 关键性质：在均衡状态下，股价每年以g增长（资本利得率=g），加上股利收益率D₁/P₀，总回报恰等于r

**多阶段增长模型（计算步骤）**：
- 适用于前期超常增长后进入稳定增长的企业（典型：科技公司/新兴企业）
- 步骤：①按超常增长率g₁逐期计算D₁, D₂, ..., DT；②计算第T期末时点的Gordon价值 PT=DT+1/(r-g₂)；③将所有Dt和PT折现至t=0后加总
- 关键：D_{T+1}=DT×(1+g₂)，PT折现时用(1+r)^T

**NPVGO模型（简答/辨析）**：
- P₀ = EPS₁/r + NPVGO：股价由"无增长部分"和"增长机会净现值"两部分构成
- NPVGO > 0：再投资ROE > r，增长创造价值（成长型股票P/E高）
- NPVGO ≤ 0：再投资ROE ≤ r，增长不创造或销毁价值；此时最优策略是100%分红
- g = b×ROE；只有ROE > r时提高留存比率b才能提升股价
