## 核心考点

**名词解释/简答高频**：CAPM模型（多校历年必考）、Beta系数（2025中财/南开）、证券市场线SML（多校）；**计算题**：已知rf、rm、Beta求资产期望收益率（CAPM公式计算，清华/中财多次）；根据实际收益判断资产是否被高估/低估（与SML比较）。**辨析**：SML vs CML（一个考β，一个考σ，适用范围不同）；CAPM vs APT（单因子vs多因子，均衡vs无套利）。**判断题**：①Beta=0的资产期望收益率=rf（不等于零）；②系统性风险是获得风险溢价的唯一来源（非系统性风险不补偿）；③市场组合Beta=1。

## 概念精讲

### 一、CAPM的前提假设

在MPT基础上追加以下假设：
1. **完全竞争市场**：所有投资者是价格接受者（无人单独影响价格）
2. **单期投资**：所有投资者持有相同的单期投资期限
3. **无摩擦市场**：无交易成本、无税收、资产无限可分
4. **同质预期**：所有投资者对所有资产的期望收益、方差、协方差有相同预期
5. **无风险借贷**：所有投资者可以无限制地以无风险利率 $r_f$ 借入或贷出资金

> **关键推论**：在同质预期下，所有投资者面对相同的有效前沿，选择相同的最优风险资产组合（基金分离定理）。市场出清时，这个最优风险组合就是**市场组合M**——包含所有风险资产、按市值比例加权的组合。

---

### 二、CAPM公式与Beta系数

**CAPM（资本资产定价模型）方程**：

$$E(r_i) = r_f + \beta_i [E(r_m) - r_f]$$

其中：
- $r_f$：无风险利率
- $E(r_m) - r_f$：**市场风险溢价**（Market Risk Premium），市场组合超出无风险资产的期望超额收益
- $\beta_i$：**Beta系数**，资产 i 的系统性风险度量

**Beta系数的定义与计算**：

$$\beta_i = \frac{Cov(r_i, r_m)}{\sigma_m^2} = \frac{\rho_{im}\sigma_i}{\sigma_m}$$

> **Beta的经济含义**：Beta 衡量资产 i 相对于市场组合（系统性因素）的风险暴露程度——即市场组合收益率变动1%时，资产 i 的期望收益率变动多少个百分点。Beta是**系统性风险的唯一度量**，也是在充分分散化组合中，决定资产定价的唯一风险因子。

| Beta值 | 含义 | 例子 |
|--------|------|------|
| β = 0 | 与市场零相关（如无风险资产）；E(r) = rf | 国债（近似） |
| β = 0.5 | 市场涨1%，资产涨0.5%；防御性资产 | 公用事业股 |
| β = 1 | 与市场同步波动；E(r) = E(rm) | 市场指数基金 |
| β = 1.5 | 市场涨1%，资产涨1.5%；进攻性资产 | 高科技股 |
| β < 0 | 与市场反向波动；E(r) < rf | 黄金（有时） |

**Beta的意义（两个层面）**：
- **风险度量**：β是单只证券在充分分散化组合中的风险贡献度；与单只证券的总风险（σ）不同——方差度量总风险，β只度量系统性风险
- **定价依据**：CAPM核心结论——在竞争均衡中，只有系统性风险（β）获得补偿，非系统性风险不获补偿（因为可免费分散掉）

### 三、证券市场线（SML）

**定义**：描述单个资产（或任意组合）的期望收益率与 Beta 之间的线性关系。

**方程**：$E(r_i) = r_f + \beta_i[E(r_m) - r_f]$（即CAPM方程本身）

**图形特征**（横轴β，纵轴E(r)）：
- 纵截距 = $r_f$（β=0时，E(r) = rf）
- 斜率 = $E(r_m) - r_f$（市场风险溢价）
- 市场组合M在 SML 上（β=1，E(r)=E(rm)）
- 所有资产在均衡时都在 SML 上

**资产定价（高估 vs 低估）**：

$$\alpha_i = \text{实际期望收益率} - \text{CAPM要求收益率} = E(r_i)_{\text{实际}} - [r_f + \beta_i(E(r_m)-r_f)]$$

| α值 | 位置 | 含义 |
|-----|------|------|
| α > 0 | SML 上方 | 实际收益 > 应有收益 → **被低估**（便宜货，应买入）|
| α = 0 | SML 上 | 均衡定价，合理 |
| α < 0 | SML 下方 | 实际收益 < 应有收益 → **被高估**（应卖出/做空）|

---

### 四、SML与CML的区别

| 对比项 | 证券市场线（SML） | 资本市场线（CML） |
|--------|----------------|----------------|
| 横轴 | **Beta**（系统性风险） | **σ**（总风险/标准差） |
| 适用对象 | **任意单个资产或任意组合** | **只适用于有效组合**（充分分散化） |
| 方程 | $E(r) = r_f + \beta[E(r_m)-r_f]$ | $E(r_p) = r_f + \frac{E(r_m)-r_f}{\sigma_m}\sigma_p$ |
| 斜率 | 市场风险溢价 $E(r_m)-r_f$ | 市场组合的夏普比率 |
| 说明什么 | 均衡下单个资产如何定价 | 有效边界上风险与收益的权衡 |

> **关键差异**：单个资产因含有非系统性风险，在以总风险σ为横轴时**不在CML上**，而是在CML下方（同等总风险下预期收益更低）。但在以β为横轴时，均衡状态所有资产**都在SML上**（无论是否分散化）。

---

### 五、CAPM的缺陷

1. **假设过于严苛**：无摩擦、同质预期、单期等假设与现实差距大（有交易成本、税收、异质预期）
2. **市场组合不可观测**：真正的市场组合包含所有资产（股票、债券、房产、人力资本等），实践中只能用股指代替（Roll's critique）
3. **单因子局限**：现实中影响资产定价的因素不止市场风险一个（规模效应、价值效应、动量效应等异象无法解释）
4. **Beta不稳定**：历史Beta并不稳定，难以准确预测未来Beta

### 六、套利定价理论（APT，Ross 1976）

**基本假设**：
- 证券收益率由**因子模型**（Factor Model）决定
- 资本市场中**不存在套利机会**（无套利条件）——若有定价偏差，套利行为会立即消除

**因子模型**：

单因子（市场）模型：$r_i = \alpha_i + \beta_i r_m + \epsilon_i$（$\epsilon_i$ 为非系统性误差）

多因子模型：$r_i = \alpha_i + \beta_{i1}F_1 + \beta_{i2}F_2 + \cdots + \beta_{ik}F_k + \epsilon_i$

**APT定价方程**：

单因子APT（与CAPM形式相同）：$E(r_i) = r_f + \beta_i \lambda$

其中 $\lambda$（Lambda）为因子风险溢价（factor risk premium）

多因子APT：$E(r_i) = r_f + \beta_{i1}\lambda_1 + \beta_{i2}\lambda_2 + \cdots + \beta_{ik}\lambda_k$

> **无套利条件的推导逻辑**：若存在无投资（0投资）、无系统风险（0风险）、正收益的套利组合，投资者会无限持有，直到价格恢复均衡。无套利均衡要求每单位系统性风险（β）的超额收益在各资产中一致（否则可套利）。

---

### CAPM与APT的比较

| 对比项 | CAPM | APT |
|--------|------|-----|
| 提出者 | Sharpe, Lintner, Mossin（1964-66） | Ross（1976） |
| 理论基础 | 均衡定价（供求均衡） | 无套利定价 |
| 风险因子 | **单因子**（市场风险β） | **多因子**（多个系统性因素） |
| 市场组合 | 需要可观测的市场组合 | 不需要（因子可灵活选取） |
| 假设严格性 | 较严格（完全市场、同质预期等） | 较宽松（主要假设：无套利） |
| 解释异象 | 无法解释规模/价值/动量等异象 | 多因子可纳入这些异象 |
| 局限性 | Roll批评、因子不可观测 | 因子选取主观；$\lambda$ 需估计 |

## 机制逻辑

**为什么只有系统性风险获得补偿**：在竞争均衡中，风险厌恶的投资者会尽量分散非系统性风险（免费可得），充分分散后每个投资者面临的剩余风险只有系统性风险。若非系统性风险有溢价，投资者会继续分散（零成本获益），直至该溢价消失。因此均衡中只有系统性风险获得定价。**β是系统性风险的正确度量**——β衡量的是资产与市场组合的协方差（而非方差），因为在大型组合中，个别资产的方差贡献在边际上趋于零，只有协方差（与市场的共同波动）才是风险贡献。

**CAPM推导的直觉**：若市场均衡时所有投资者都持有市场组合M，那么要使资产i被纳入M并被充分持有，它的预期收益率必须恰好补偿其对M的边际风险贡献。该边际风险贡献正比于Cov(ri, rm)/σm²，即β。高β资产对组合风险贡献大，需要更高的期望收益作为补偿；低β甚至负β资产提供"保险"功能，期望收益可以低于rf（如β<0）。

**APT的套利逻辑**：假设只有一个因子，有两个资产β相同但预期收益不同（资产A期望10%，资产B期望8%）。构建套利组合：做多A + 做空B（等额），该组合β=0（无系统风险）、净投资=0，但期望收益=2%。这是"无本万利"——套利者会大量买A卖B，推高A价格（降低其收益率）并压低B价格（推高其收益率），直到两资产期望收益相等，套利机会消失。

## 比较辨析

| 对比项 | Beta（β） | Alpha（α） |
|--------|---------|----------|
| 含义 | 系统性风险的暴露度（敏感性） | 实际收益 vs CAPM应有收益的偏差 |
| 决定因素 | 与市场的协方差 | 市场定价效率（错误定价程度） |
| 均衡时 | 每个资产都有唯一β | α = 0（市场均衡时无α）|
| 投资意义 | 构建所需系统风险暴露 | α > 0说明被低估，买入机会 |

| 对比项 | 单因子APT | 多因子APT（FF三因子等）|
|--------|---------|---------------------|
| 因子数量 | 1个（市场因子）| 多个（市场+规模+价值等）|
| APT方程 | E(ri) = rf + βiλ | E(ri) = rf + β₁λ₁+β₂λ₂+… |
| 解释能力 | 类似CAPM，有限 | 更好解释横截面收益差异 |

## 答案要点

**CAPM（名词解释/简答）**：
- 资本资产定价模型（CAPM）是在MPT基础上，加入完全市场、单期、同质预期等假设推导出的资产均衡定价模型
- 公式：E(ri) = rf + βi[E(rm) - rf]，其中rf为无风险利率，βi为资产系统性风险，E(rm)-rf为市场风险溢价
- 核心结论：资产的期望超额收益与其Beta线性正相关；只有系统性风险（β）获得补偿，非系统性风险不获补偿（可分散消除）
- 证券市场线（SML）：描述所有资产期望收益与β的线性关系图，均衡时所有资产都在SML上；实际收益高于SML对应收益（α>0）则被低估，低于SML则被高估

**Beta系数（名词解释）**：
- Beta（β）系数是资产系统性风险的度量，定义为：β = Cov(ri, rm)/σm²
- 含义：衡量资产相对于市场组合的敏感性，即市场组合收益变动1%时，资产收益的变动幅度
- β=1时与市场同步；β>1为进攻性资产（高风险高收益预期）；β<1为防御性资产；β=0期望收益=rf；市场组合β=1
- CAPM中β是唯一的定价风险因子，非系统性风险不被定价

**SML与CML的区别（简答）**：
- CML（资本市场线）：横轴为总风险σ，描述有效组合（充分分散化）的期望收益与总风险的线性关系，只适用于有效组合（在CML上的组合无非系统性风险）
- SML（证券市场线）：横轴为系统性风险β，描述任意单个资产或任意组合的期望收益与β的线性关系，适用于所有资产（包括单只股票）
- 区别：单只股票含有非系统性风险，在以σ为横轴时在CML下方；但在以β为横轴时，均衡下落在SML上

**CAPM缺陷（简答）**：
- ①假设过于严苛：无摩擦、同质预期、单期假设与现实差距大
- ②市场组合不可观测（Roll批评）：真实市场组合包含所有资产（含房产、人力资本），实践只能用股指代替，检验结论不可靠
- ③单因子局限：无法解释规模效应、价值效应、动量等实证异象
- ④Beta不稳定：历史Beta预测能力有限

**APT（套利定价理论，名词解释/简答）**：
- APT由Ross（1976）提出，基于无套利条件（而非均衡）推导的多因子资产定价模型
- 核心假设：①收益率由多个系统性因子决定（因子模型）；②不存在套利机会（零投资零风险正收益的组合不存在）
- 多因子APT方程：E(ri) = rf + β₁λ₁+β₂λ₂+…+βkλk，其中βk为因子敏感性，λk为因子风险溢价
- 与CAPM比较：APT假设更宽松（不需要市场组合、同质预期），因子更灵活（多因子），但因子选取主观且因子风险溢价需估计
