## 核心考点

**名词解释高频**：增量现金流（2025华东师大/2026山大）、机会成本（2025厦大/天大）、沉没成本（2024厦大）、实物期权（2020/2025贵大/2026中财）、盈亏平衡点（2024天大/首经贸/中财）。**简答**：机会成本与沉没成本的区别（2024贵大/央民）；增量现金流含义及为何关注（2026首经贸）；资本预算方法比较（多所学校）。**计算**：会计盈亏平衡点/现值盈亏平衡点公式计算（2021中财/2024贵大/中财/2025人大）。**判断**：沉没成本不属于增量现金流（正确）；利息属于融资成本不考虑（正确）；ΔNWC<0是现金流入（正确）。

## 概念精讲

### 一、增量现金流（Incremental Cash Flow, ICF）

**定义**：增量现金流 = 接受该项目后产生的现金流 - 没有该项目时的现金流

> **为什么必须使用增量现金流**：投资决策的核心是"因采用该项目而发生的额外变化"。只有增量现金流才能衡量项目对企业价值的净贡献。过去已发生（沉没成本）或无论如何都会发生的现金流与决策无关，不应纳入分析。

**需要考虑的现金流（相关现金流）**：
1. **经营性现金流（OCF）**：销售收入、付现成本、税收、折旧税盾
   - OCF = (Sales − Cost) × (1−t) + Dep × t（税盾法）= NI + Dep（自下而上法）
2. **资本性支出（CAPEX）**：购买或出售与项目相关的固定资产
3. **净营运资本变动（ΔNWC）**：与项目相关的营运资本变动（ΔNWC > 0 为现金流出）
4. **机会成本（Opportunity Cost）**：为从事该项目而放弃的其他活动的收入。即使资产"已拥有"，其市场价值仍是机会成本，必须计入
5. **副效应**：协同效应（synergy）新项目增加原有产品销量；侵蚀效应（erosion）新项目减少原有产品销量

**不需要考虑的现金流（无关现金流）**：
- **沉没成本（Sunk Cost）**：已经发生、无法收回的成本。无论是否进行项目都已支出，与决策无关
- **融资成本**：融资活动产生的成本（如利息支出）。利息已在折现率中体现，计入OCF会造成重复计算

> **沉没成本 vs 机会成本**：沉没成本是过去已发生、不可追回的支出，不纳入增量现金流；机会成本是因选择该项目而放弃的最佳替代方案的收益，必须纳入增量现金流。例：某公司已花费50万元做市场调研（沉没成本），决定是否建厂时，该50万不计；但如果厂址现在可以出租获得10万/年，则该10万是机会成本，必须计入。

### 二、折旧方法

**直线折旧法（年限平均法）**：
$$\text{年折旧额} = \frac{\text{固定资产原值} - \text{预计净残值}}{\text{预计使用年限}}$$

**加速折旧法**：

**A. 余额递减法**：年折旧额 = 账面净值 × 折旧率（折旧率使末年净值 = 残值）

**B. 双倍余额递减法**：
- 前期：年折旧额 = 账面净值 × (2/预计使用年限)
- **最后两年改为直线法**（转换时机：当直线法年折旧额 ≥ 双倍余额递减法年折旧额时）

**C. 年数总和法**：
$$\text{年折旧额} = (\text{固定资产原值} - \text{预计净残值}) \times \frac{\text{尚可使用年数}}{\text{年数总和}}$$

> **加速折旧的意义**：加速折旧法在早期提取更多折旧，产生更大折旧税盾（Dep×t），税盾现值更高，对企业更有利。会计上利润前期低、后期高；现金流前期更大。

### 三、项目现金流框架（增量现金流矩阵）

计算NPV的标准框架：逐期计算各类现金流之和即FCFF，再折现求NPV。

| 现金流 | t=0（初始） | t=1 | t=2 | … | t=n（终止） |
|--------|------------|-----|-----|---|------------|
| OCF | 0 | OCF₁ | OCF₂ | … | OCFₙ |
| CAPEX | −初始投资 | 0 | 0 | … | +残值净收入 |
| ΔNWC | −ΔNWC₀ | 0 | 0 | … | +NWC回收 |
| **FCFF合计** | CF₀ | CF₁ | CF₂ | … | CFₙ |

> **注意事项**：①初始期CAPEX为负（支出），终止期若出售资产有税后残值现金流入；②NWC在项目结束时全额收回（流入）；③CAPEX包括旧设备出售的税后现金流；④固定资产出售时：税后现金流 = 市场价 - (市场价 - 账面值) × t

### 四、新建决策 vs 重置决策

**新建决策**：直接计算新项目的增量现金流（OCF/CAPEX/ΔNWC），再用NPV法判断是否投资。

**重置决策**（设备更新）：需比较"保留旧设备"与"换用新设备"两条路径的增量现金流差额。

框架：
1. 分别计算"继续用旧设备"的增量现金流和"购买新设备"的增量现金流
2. 计算两者差额（新设备 - 旧设备）= 换新设备的增量效益
3. 若增量NPV > 0，则应该更换

> **重置决策要点**：出售旧设备的市场价（机会成本！不是账面值）是t=0的现金流入；旧设备未来的维护成本是保留旧设备的现金流出（要算税后）；折旧差额产生税盾差额。

**等年值成本法（EAC，约当年均成本）**：当两个互斥设备使用年限不同时，不能直接比NPV（年限长的NPV可能大），应将各方案的NPV换算为年金进行比较：
$$EAC = \frac{NPV}{PVIFA(r, n)}$$
EAC更小的方案更优（年均成本更低）。

### 五、盈亏平衡分析

**含义**：通过盈亏平衡点（Break-Even Point）分析项目成本与收益的平衡，找出使项目刚好不亏损所需的最低销量。

**① 会计盈亏平衡点（利润盈亏平衡点）**：使净利润 = 0 的销量

$$Q^* = \frac{FC + Dep}{P - VC}$$

其中 FC = 固定成本（不含折旧），P = 售价，VC = 单位变动成本，Dep = 折旧。

**② 现值盈亏平衡点（财务盈亏平衡点）**：使项目 NPV = 0 的销量

$$Q^* = \frac{EAC + FC(1-t) - Dep \cdot t}{(P-VC)(1-t)}$$

其中 $EAC = \dfrac{CAPEX}{PVIFA(r,n)}$（初始投资的等年值成本）

> **哪个盈亏平衡点更大？** 现值盈亏平衡点 > 会计盈亏平衡点。原因：会计盈亏平衡点只要求回收折旧（非现金成本），而现值盈亏平衡点要求回收全部初始投资的机会成本（EAC > Dep，因为EAC包含了资金的时间价值）。满足会计盈亏平衡的项目NPV为负；只有达到现值盈亏平衡，NPV才等于0。

### 六、敏感性分析、场景分析与蒙特卡罗模拟

| 方法 | 含义 | 优点 | 缺点 |
|------|------|------|------|
| **敏感性分析** | 改变某一变量（其他不变），观察NPV变化 | 识别关键变量，判断NPV稳健性 | 孤立处理单一变量，忽略变量间相关性；可能造成"安全错觉" |
| **场景分析** | 多个变量同时变化（设定悲观/基准/乐观场景） | 考虑了变量间相关性，更全面 | 场景构建困难；不能提供明确决策建议 |
| **蒙特卡罗模拟** | 为每个变量设定概率分布，随机模拟NPV分布 | 明确指出变量间相互作用，最全面 | 计算复杂，依赖变量分布假设 |

### 七、实物期权（Real Options）

**定义**：实物期权是指在项目投资中，在不确定情况下公司具有的**调整决策的权利**。传统NPV法不考虑未来调整的灵活性，低估了项目的真实价值。

**三类实物期权**：
- **拓展期权（扩张期权）**：若项目成功，可扩大规模进一步投资
- **放弃期权**：若项目失败，可提前出售资产止损，减少损失
- **择机期权（等待期权）**：可等待获取更多信息后再决策（等待本身有价值）

**分析方法：决策树**（用概率加权NPV）

> **实物期权的意义**：项目真实价值 = 静态NPV + 实物期权价值。即使静态NPV略为负，若实物期权价值较高，项目仍可能值得投资。

## 机制逻辑

**为什么融资成本（利息）不纳入增量现金流**：NPV法的折现率已经包含了资本的机会成本（包括债务成本）。若同时在分子扣除利息、在分母体现债务成本，等于双重计算融资成本，导致NPV低估。因此FCFF计算中不扣除利息（用OCF），再以WACC折现，将融资效应统一放在分母。

**为什么现值盈亏平衡点 > 会计盈亏平衡点**：会计盈亏平衡只需 (P-VC)Q = FC + Dep，即每年OCF = (Sales-Cost)(1-t) + Dep×t > 0（存在利润即可）；而现值盈亏平衡要求所有年度OCF的现值恰好等于初始投资（NPV = 0），年均须覆盖EAC = CAPEX/PVIFA > Dep（因为EAC还包括资金机会成本）。

**折旧对税后现金流的双重作用**：折旧上升 → 利润下降（会计上亏损增加）→ 但税款减少（折旧税盾=Dep×t）→ OCF = NI + Dep，净效果是OCF随折旧增加而增加。这是加速折旧有利于企业的机制。

## 比较辨析

| 对比项 | 沉没成本 | 机会成本 |
|--------|---------|---------|
| 时间维度 | 过去已发生 | 未来将放弃 |
| 是否纳入增量CF | ❌ 不纳入 | ✅ 必须纳入 |
| 典型例子 | 已花的研发费用、市场调查费 | 自有资产的市场出租价值 |
| 经济逻辑 | 无法改变，与当前决策无关 | 真实的代价，决策应权衡 |

| 对比项 | 会计盈亏平衡 | 现值盈亏平衡 |
|--------|------------|------------|
| 目标量 | 净利润 = 0 | NPV = 0 |
| 公式 | (FC+Dep)/(P-VC) | [EAC+FC(1-t)-Dep×t]/[(P-VC)(1-t)] |
| 相对大小 | 较小 | 较大 |
| 经济含义 | 不亏钱（会计）| 创造价值（经济） |
| 若仅满足会计BE | NPV < 0 | 项目不可行 |

## 答案要点

**增量现金流（名词/简答）**：
- 增量现金流（ICF）= 接受项目后产生的现金流 - 未接受该项目时的现金流，反映项目带来的实际边际变化
- 应考虑：OCF（经营性现金流）、CAPEX（资本性支出）、ΔNWC（净营运资本变动）、机会成本、副效应（协同/侵蚀）
- 不应考虑：沉没成本（已发生无法收回）、融资成本（利息已在折现率中体现）
- 必须使用增量现金流原因：过去已支出（沉没成本）与当前决策无关；若纳入利息则双重计算融资成本；评估项目创造价值须基于其净边际贡献

**机会成本 vs 沉没成本（简答）**：
- 沉没成本：已经发生、无法收回的成本，无论项目实施与否均已支出，不应纳入投资决策
- 机会成本：为从事某项目而不得不放弃的其他最佳机会所对应的收益，是真实的经济代价，必须计入增量现金流
- 核心区别：沉没成本面向过去（无法改变），机会成本面向未来（可以影响决策）

**实物期权（名词解释）**：
- 实物期权是企业在不确定性下调整投资决策的权利，是传统NPV法忽略的灵活性价值
- 三类：①拓展期权（成功时扩大规模）；②放弃期权（失败时提前出售资产止损）；③择机期权/等待期权（等待更多信息后再投资）
- 项目真实价值 = 静态NPV + 实物期权价值；实物期权的存在使实际价值高于静态NPV法的估计

**会计盈亏平衡点（名词解释）**：
- 会计盈亏平衡点（Q*）= 使净利润恰好为0的销售数量，公式：Q* = (FC + Dep)/(P - VC)
- 达到会计盈亏平衡时，企业不亏损但NPV < 0（未创造经济价值），因为尚未覆盖初始投资的机会成本

**现值盈亏平衡点（名词解释）**：
- 现值盈亏平衡点（Q*）= 使项目NPV恰好为0的销售数量，公式：Q* = [EAC + FC(1-t) - Dep×t]/[(P-VC)(1-t)]，其中EAC = 初始投资/PVIFA(r,n)
- 现值盈亏平衡点 > 会计盈亏平衡点，因为前者要求OCF覆盖等年值成本EAC（含资金机会成本），后者只要求覆盖折旧
