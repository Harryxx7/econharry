## 核心考点

**选择题/名词解释**：准备金的辨析（法定准备金 vs 超额准备金 vs 存款准备金 vs 库存现金）是判断题高频考点。贷款五级分类标准（逾期90/270/360天触发线）和不良贷款构成是选择题常考。6C原则是名词解释考点。

## 概念精讲

**资产业务**：将负债业务筹集的资金加以运用的业务，是银行获取收益的主要来源。

按流动性分类：**一级准备 → 二级准备 → 贷款**（流动性依次递减，收益性依次递增）

---

### ① 一级准备（现金资产）

- 库存现金
- 存放央行（法定存款准备金 + 超额存款准备金）
- 同业资产（同业拆出 + 逆回购 + 同业存款）
- 在途资金

> **【辨析】准备金的口径**：
> - **法定准备金** = 法定存款准备金
> - **超额准备金** = 超额存款准备金 + **库存现金**
> - **存款准备金** = 法定存款准备金 + 超额存款准备金（不含库存现金）
> - **准备金（总）** = 法定准备金 + 超额准备金 = 存款准备金 + 库存现金

---

### ② 二级准备（证券资产）

债券、股票等流动性较强的有价证券，可迅速变现补充一级准备。

---

### ③ 贷款（最重要的资产业务）

**按期限**：短期（≤1年）、中期（1-5年）、长期（>5年）

**按保障条件**：信用贷款、保证贷款（票据贴现纳入贷款管理范畴）

**贷款五级分类（信贷资产质量分类标准）**：

| 分类 | 是否不良 | 标准 |
|------|---------|------|
| **正常** | — | 按时足额还本付息 |
| **关注** | — | 有能力，但存在不利因素 |
| **次级** | ✅不良 | 正常营业收入无能力还款 |
| **可疑** | ✅不良 | 抵押担保也无能力还款 |
| **损失** | ✅不良 | 所有可能措施均无能力还款 |

**逾期天数硬性标准**：逾期 → 至少关注；逾期90天 → 至少次级；逾期270天 → 至少可疑；逾期360天 → 至少损失

**不良贷款率** = 不良贷款 / 总贷款

**6C原则（银行筛选借款人）**：

| 维度 | 英文 | 核心含义 |
|------|------|---------|
| 资本 | Capital | 资本金规模越大，贷款可能性越高 |
| 偿债能力 | Capacity | 资产负债率、利息倍数等指标 |
| 品质 | Character | 个人/企业还款意愿 |
| 抵押和担保 | Collateral | 抵押物越充足，贷款可能性越高 |
| 环境 | Condition | 企业/个人经营就业环境 |
| 连续性 | Continuity | 企业续营能力 |

## 答案要点

**准备金辨析（判断题）**：
- 超额准备金 = 超额存款准备金 + 库存现金（库存现金属于超额准备金的一部分）
- 存款准备金 = 法定 + 超额存款准备金（不含库存现金）
- 总准备金 = 存款准备金 + 库存现金

**贷款五级分类（简答）**：
- 正常、关注（非不良）+ 次级、可疑、损失（不良）
- 逾期90/270/360天分别至少计入次级/可疑/损失
- 不良贷款率 = 不良贷款 / 总贷款

**6C原则（名词解释）**：商业银行评估借款人信用的六维度：Capital（资本）、Capacity（偿债能力）、Character（品质）、Collateral（抵押担保）、Condition（环境）、Continuity（连续性）
