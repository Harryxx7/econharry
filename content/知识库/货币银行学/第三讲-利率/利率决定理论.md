## 核心考点

**选择题高频**：到期收益率定义、名义利率/实际利率区分、费雪效应计算（r≈i-π）、我国基准利率体系（DR007/LPR）是反复考查的固定考点。**简答/论述高频**：古典vs凯恩斯利率决定理论的变量与逻辑对比（一定要写清楚"什么市场、哪个变量、名义还是实际"）；流动性偏好三动机（交易/预防/投机）单独出名词解释。IS-LM模型常以比较静态分析形式出现。

## 概念精讲

**利率的含义**：
- **简单定义**：借贷期满形成的利息额与本金的比率
- **精确定义（到期收益率，YTM）**：使债务工具未来收益的现值之和等于当前市场价格的贴现率

$$P = \frac{C}{(1+y)} + \frac{C}{(1+y)^2} + \cdots + \frac{C}{(1+y)^n} + \frac{B}{(1+y)^n}$$

> **利率 = 无风险利率（货币时间价值）+ 风险溢价**。YTM是债券持有人对债券要求的综合报酬率，反映了市场参与者对未来所有风险的要求补偿。债券价格（P）与YTM反向变动——利率上升→债券价格下跌，利率下降→债券价格上升。

**利率的分类**（多个维度）：

| 分类维度 | 类型 | 含义 |
|---------|------|------|
| 是否由市场决定 | 官定利率 | 政府或央行直接控制 |
| | 市场利率 | 市场供求自发决定 |
| | 公定利率 | 金融行业自律组织（如银行同业协会）制定 |
| 在体系中的地位 | **基准利率** | 整个利率体系的基础，起决定性作用；发生变动时，其他利率相应变动 |
| | 一般利率 | 在基准利率基础上加减点形成 |
| 是否含通胀调整 | 名义利率（i） | 包含通货膨胀因素，描述"货币生货币"的速度 |
| | 实际利率（r） | 剔除通货膨胀后，描述"商品生商品"的速度 |
| 借贷期间是否变动 | 固定利率 | 借贷期间不变 |
| | 浮动利率 | 借贷期间可定期调整 |

**我国基准利率体系**（利率传导框架）：央行每日开展逆回购操作（政策利率）→ 7天逆回购利率（OMO利率）→ 传导至：
- **货币市场**：DR007（存款类金融机构7天回购利率，当前市场基准利率）
- **债券市场**：国债收益率
- **贷款市场**：LPR（贷款市场报价利率，1年期/5年以上，为贷款定价基准）
- **存款市场**：存款利率

> 重要利率品种：SHIBOR（上海银行间同业拆借利率，信用等级较高的银行算术平均报价）；LPR是商业银行对最优质客户贷款利率的报价均值，是贷款利率定价核心参考；**存款基准利率不是当前市场基准利率**（已放开）。

**名义利率 vs 实际利率（费雪效应）**：

$$i \approx r + \pi^e \quad \text{或} \quad r \approx i - \pi^e$$

费雪认为**实际利率长期稳定**，名义利率与预期通胀率之间存在一一对应关系——预期通胀率上升1%，名义利率上升约1%。一般观测到的利率为名义利率；居民消费/储蓄和企业投资决策更关注实际利率。

**古典利率决定理论（实际利率决定理论）**：

- **变量**：产品市场的储蓄（S）和投资（I）
- **逻辑**：
  - 储蓄 = 资金供给，与利率**正相关**（利率是延期消费的报酬，利率越高储蓄越多）：$S(r) = \bar{S} + ar,\; a>0$
  - 投资 = 资金需求，与利率**负相关**（利率是资本成本，利率越高投资越少）：$I(r) = \bar{I} - br,\; b>0$
  - 产品市场出清（S = I）决定均衡**实际利率** r*

**凯恩斯利率决定理论（流动性偏好理论）**：

- **变量**：货币市场的货币需求（$M_D$）和货币供给（$M_S$）
- **货币需求三动机**：
  - **交易动机**：为满足日常交易持有货币，产生于收入和支出的不同步性，与**收入正相关**
  - **预防动机**：为满足意料之外支出而持有货币，产生于支出的不确定性，与**收入正相关**
  - **投机动机**：在有息债券和无息货币之间配置资产，与**利率负相关**（安全利率分析法：利率低于安全利率→预期利率上升→债券价格下跌→增持货币）
  - 合计：$M_D(i) = \bar{M}_D - ci,\; c>0$
- **货币供给**：央行完全控制的外生变量：$M_S = \bar{M}_S$
- **货币市场出清**（$M_D = M_S$）决定均衡**名义利率** i*

**可贷资金理论（综合理论）**：将古典理论和凯恩斯理论综合，可贷资金供给 = 储蓄 + 货币供给增量（ΔMs），可贷资金需求 = 投资需求 + 货币窖藏增量（ΔMd），两者共同决定均衡利率。

**IS-LM模型**：
- **IS曲线**：产品市场均衡（S=I），反映利率与收入的负相关关系（向右下倾斜）。财政政策 → IS曲线移动。
- **LM曲线**：货币市场均衡（$M_D=M_S$），反映利率与收入的正相关关系（向右上倾斜）。货币政策 → LM曲线移动。
- **均衡**：IS与LM的交点**同时决定均衡利率和均衡收入**，超越了古典（仅决定实际利率）和凯恩斯（仅决定名义利率）单一市场框架。

## 机制逻辑

**古典 vs 凯恩斯 的关键差异**：古典理论把利率视为**"真实"变量**（实际利率），由产品市场储蓄-投资均衡决定，货币中性；凯恩斯把利率视为**"货币"变量**（名义利率），由货币市场流动性偏好-货币供给均衡决定，货币政策直接影响利率，利率再影响投资和总需求。

**货币供给增加 → 利率下降的传导**（凯恩斯框架）：央行扩大货币供给 → 货币市场货币供给曲线右移 → 在原均衡名义利率水平上货币供过于求 → 人们用多余货币购买债券 → 债券价格上升 → 名义利率下降。

**费雪效应的政策含义**：若央行扩大货币供给导致通胀预期上升，名义利率反而上升（通胀对名义利率的推升效果），实际利率未必下降——这是货币政策传导需要考量的约束。

## 比较辨析

| 对比项 | 古典利率决定理论 | 凯恩斯利率决定理论 |
|--------|---------------|---------------|
| 决定市场 | 产品市场 | 货币市场 |
| 均衡条件 | S（储蓄）= I（投资） | $M_D$（货币需求）= $M_S$（货币供给） |
| 决定的利率 | 实际利率 | 名义利率 |
| 资金供给来源 | 储蓄 | 货币供给（外生） |
| 资金需求来源 | 投资 | 持币需求（交易+预防+投机） |
| 货币作用 | 中性（不影响实际利率） | 非中性（货币供给直接影响利率） |

| 对比项 | 交易动机 | 预防动机 | 投机动机 |
|--------|---------|---------|---------|
| 来源 | 收支不同步 | 支出不确定性 | 资产配置选择 |
| 决定因素 | 收入水平↑→货币需求↑ | 收入水平↑→货币需求↑ | 利率↑→货币需求↓ |
| 与利率关系 | 基本无关 | 基本无关 | **负相关** |

## 答案要点

**到期收益率（名词解释）**：
- 使债务工具未来各期现金流折现值之和等于当前市场价格的贴现率（即内部收益率）
- 是利率最精确的定义，反映债券持有人对债券要求的综合报酬率
- 与债券价格反向变动：利率上升→债券价格下跌；利率下降→债券价格上升

**名义利率与实际利率（费雪效应，简答）**：
- 名义利率（i）：包含通货膨胀因素的利率，反映"货币生货币"的速度；一般直接观测到的利率均为名义利率
- 实际利率（r）：剔除通货膨胀预期后的利率，反映真实购买力的增长速度；r ≈ i - πe
- 费雪效应：费雪认为实际利率长期保持稳定，名义利率与预期通胀率一一对应；预期通胀率↑→名义利率同幅上升；居民消费、储蓄和企业投资决策应以实际利率为依据

**基准利率（名词解释）**：
- 整个利率体系的基础和标准，是在多种利率并存条件下起决定性作用的利率；当基准利率变动时，其他利率相应变动
- 我国基准利率体系：货币市场以DR007为基准；债券市场以国债收益率为基准；贷款市场以LPR（贷款市场报价利率）为基准；美国以联邦基金利率（FFR）为基准

**古典利率决定理论（简答）**：
- 变量：产品市场的储蓄和投资
- 储蓄代表资金供给，与实际利率正相关（利息是延期消费的报酬）
- 投资代表资金需求，与实际利率负相关（利率是资本成本）
- 产品市场出清（S = I）决定均衡实际利率；货币中性，货币供给变化不影响实际利率

**凯恩斯流动性偏好理论（简答）**：
- 变量：货币市场的货币需求（流动性偏好）和货币供给
- 货币需求三动机：交易动机（收支不同步，与收入正相关）；预防动机（支出不确定，与收入正相关）；投机动机（债券与货币间的资产配置选择，与利率负相关）
- 货币供给由央行完全控制（外生变量）
- 货币市场出清（MD = MS）决定均衡名义利率；货币供给增加→利率下降→投资增加→收入增加
