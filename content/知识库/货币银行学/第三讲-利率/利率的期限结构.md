## 核心考点

**简答/论述必考**：三大期限结构理论的假设、结论及对三条经验法则的解释能力是每年必考比较辨析题。**流动性溢价理论**能解释全部三条经验法则（最优）。**收益率曲线倒挂**预示经济衰退是判断题固定考点。远期利率与预期短期利率的关系需掌握各理论下的不同结论。

## 概念精讲

### 收益率曲线

**含义**：期限不同的**同类债券**到期收益率与到期时间之间的关系曲线。

**国债收益率曲线斜率**（通常用10年期国债收益率 - 3个月国库券利率衡量）：

| 斜率形态 | 含义 | 对经济的预示 |
|---------|------|------------|
| **向上倾斜（陡峭）** | 长期利率 > 短期利率，期限溢价高 | 市场乐观，预期经济扩张 |
| **平坦** | 长期利率 ≈ 短期利率 | 经济转折信号 |
| **倒挂（向下倾斜）** | 长期利率 < 短期利率，期限溢价为负 | 市场悲观，**预示经济衰退**（重要前瞻指标） |

---

### 三条经验法则

1. 各期限债券收益率**往往同向波动**（短期利率↑，长期也倾向于↑）
2. 短期利率**低**时，收益率曲线**更容易向上倾斜**；短期利率高时更容易倒挂
3. 收益率曲线**通常向上倾斜**（正向斜率为常态）

---

### 三大期限结构理论对比

**① 预期理论**

| 要素 | 内容 |
|------|------|
| **假设** | 投资者风险中性；不同期限债券完全替代；资金完全自由流动 |
| **结论** | 长期利率 = 期限内预期短期利率的**算术平均值** |
| | 远期利率 = 预期的未来短期利率（无溢价） |
| **解释法则** | ✅法则1（同向波动：短期利率变化影响长期预期）✅法则2（均值回归） ❌法则3（无法解释为何通常正斜率） |

**② 市场分割理论**

| 要素 | 内容 |
|------|------|
| **假设** | 投资者风险厌恶；不同期限债券**不可替代**；资金不可流动 |
| **结论** | 长期利率与预期短期利率**无关**（各期限市场独立决定） |
| | 远期利率与预期短期利率无关 |
| **解释法则** | ❌法则1（无跨市场联动） ❌法则2 ✅法则3（长期债券供少需多 → 价格高 → 利率低...实际上解释的是正斜率常态） |

**③ 流动性溢价理论（首选理论）**

| 要素 | 内容 |
|------|------|
| **假设** | 投资者部分风险厌恶；不同期限债券**不能完全替代**；资金部分流动 |
| **结论** | 长期利率 = 期限内预期短期利率均值 **+ 流动性溢价（LP）** |
| | 远期利率 = 预期短期利率 + 流动性溢价 |
| | 流动性溢价 > 0，且随期限延长而增加（短期投资者居多，长期债券需额外补偿） |
| **解释法则** | ✅法则1（资金流动）✅法则2（均值回归）✅法则3（流动性溢价使曲线天然向上倾斜） |

> **流动性溢价理论为何优于另外两者**：既保留了预期理论的跨市场联动性（资金部分流动），又加入了市场分割理论的风险厌恶假设（流动性溢价），能同时解释三条经验法则。

## 比较辨析

| 理论 | 法则1 | 法则2 | 法则3 | 关键假设 |
|------|:---:|:---:|:---:|---------|
| 预期理论 | ✅ | ✅ | ❌ | 风险中性，完全替代 |
| 市场分割理论 | ❌ | ❌ | ✅ | 风险厌恶，完全不替代 |
| **流动性溢价理论** | ✅ | ✅ | ✅ | 风险厌恶，部分替代 |

## 答案要点

**利率期限结构三大理论（简答/论述）**：
- **预期理论**：投资者风险中性，不同期限完全替代；长期利率=预期短期利率均值；能解释法则1、2，不能解释法则3（无法解释为何收益率曲线通常向上倾斜）
- **市场分割理论**：投资者风险厌恶，不同期限完全不可替代；各期限利率独立决定；只能解释法则3，不能解释法则1、2
- **流动性溢价理论**：风险厌恶，部分替代；长期利率=预期短期利率均值+流动性溢价（LP>0且随期限增大）；能解释全部三条法则，是最合理的理论

**收益率曲线倒挂（名词解释）**：
- 含义：长期国债收益率低于短期国债收益率，曲线呈向下倾斜
- 根据预期/流动性溢价理论：倒挂意味着市场预期未来短期利率大幅下降（即预期经济衰退，央行将降息）
- 应用：收益率曲线倒挂是历史上最可靠的经济衰退预警指标之一
