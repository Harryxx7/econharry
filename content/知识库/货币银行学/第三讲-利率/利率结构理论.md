## 核心考点

**超高频**：利率期限结构三大理论（预期/市场分割/流动性溢价）的假设-结论-对经验法则的解释力，每年必考且常考比较简答。收益率曲线的四种形状和**倒挂预警作用**（倒挂→经济衰退信号）近年尤受关注。风险结构中违约风险、流动性风险的分析（通过图形推导利率变化方向）是选择题常客；**TED利差、TIPS**是名词解释高频词。

## 概念精讲

**利率风险结构**：具有**相同到期期限**的债券，因为风险不同而导致的利率差异（即"风险溢价"的来源）。

**违约风险（信用风险）**：债务人无法按时足额偿还本息的可能性。

> **国债 vs 企业债**：国债背后是政府信用（以税收为后盾，本金一般展期，利息须用税收支付）→ 违约风险极低。企业债背后是企业信用（以企业收入和资产支撑），违约可能性高于国债。信用评级下调 → 市场要求更高风险溢价 → 债券价格下跌 → 利率上升。

**信用评级机构**：全球三大：标准普尔（S&P）、穆迪（Moody's）、惠普（Fitch）。标普评级BB及以下（穆迪Ba及以下）= "垃圾债"，也称"投机级"或"高收益"债券。国内三大评级机构：大公国际、上海新世纪、东方金城；国内评级普遍虚高（81%企业能评到AA及以上）。

**TED利差**：三个月期欧洲美元同业拆借利率（LIBOR）与三个月期美国国库券利率之差。衡量市场情绪和金融系统压力的重要指标——经济衰退或金融危机爆发时，LIBOR上升（银行间不信任，信用利差扩大）而国库券利率下降（避险资金涌入），TED利差急剧上升。

**流动性风险**：债券在必要时难以迅速变现而给债权人带来损失的可能性。变现成本越高，流动性风险越大。

> 变现成本三要素：①**交易佣金**（支付给经纪商的手续费）；②**买卖价差（bid-ask spread）**：做市商报出的买入价与卖出价之差，买卖价差越大变现成本越高；③**市场冲击**：取决于市场规模/深度，市场规模越小、冲击越大、变现成本越高。企业债的买卖价差和市场冲击均高于国债 → 企业债流动性更弱 → 须支付更高利率补偿。

**税收风险**：债券税收因素（差异）导致的损失可能性。税前vs税后收益率：$y_a = y_b(1-t)$。经典案例：美国地方债（州和地方政府债券）利率低于联邦国债，尽管其信用风险和流动性风险更高——原因是地方债利息收入**免征联邦所得税**，税后实际收益率更高，因此投资者接受更低的税前利率。

**通货膨胀风险（其他债券相对于TIPS而言）**：通货膨胀导致债权人实际购买力损失的可能性。

> **TIPS（通胀保护证券，Treasury Inflation Protected Securities）**：以实际利率报价，面值与物价指数（CPI）挂钩，票面利率固定，但本金随物价调整，从而保障持有人的真实购买力。应用：**盈亏平衡通胀率**（Break-even Inflation Rate）= 10年期国债利率 - 10年期TIPS利率，衡量市场对未来通胀的预期水平。

**内嵌期权风险**：由于某些期权性质条款（可赎回、可转换、可卖回等）给债权人带来的损失可能性。可赎回债券（Call Option属于发行人）→ 对投资者不利 → 须补偿更高利率；可转换债券（对投资者有利）→ 投资者接受更低利率。

**利率期限结构**：具有**相同风险结构**的同种债券，因为到期期限不同而导的利率差异。

**收益率曲线（Yield Curve）**：横轴为到期时间，纵轴为到期收益率，描绘不同期限同类债券到期收益率的关系。四种典型形状：
1. 向上倾斜（正斜率，正常形态）：长期利率 > 短期利率
2. 向下倾斜（倒挂/负斜率）：长期利率 < 短期利率——历史上多次先于经济衰退出现
3. 水平（平坦）：长短期利率相近
4. 驼峰形（中期最高）

**期限溢价（Term-Spread）**：10年期国债收益率 - 3月期国库券收益率。重要前瞻性指标：期限溢价较高（收益率曲线陡峭上倾）→ 预示未来经济趋于繁荣；期限溢价较低甚至为负（收益率曲线平坦或倒挂）→ 预示未来经济趋于衰退。

**期限结构的三条经验法则**（历史数据观察）：
1. 各期限债券收益率**同向波动**（相关性高）
2. 短期利率**较低时**，收益率曲线更倾向于向上倾斜；短期利率**较高时**，收益率曲线更倾向于向下倾斜
3. 收益率曲线往往是**向上倾斜**的（长期利率通常高于短期利率）

**期限结构理论**（解释经验法则的三种理论）：

| 理论 | 前提假设 | 核心结论 | 对经验法则的解释力 |
|------|---------|---------|--------------|
| **预期理论**（纯粹预期理论） | 投资者风险中性；不同期限债券**完全可替代**；资金完全流动 | 长期利率 = 期限内预期短期利率的**算术平均值**：$y_n = \frac{\sum_{j=1}^{n}E(r_j)}{n}$；远期利率 = 预期短期利率：$f_n = E(r_n)$ | ✅同向波动；✅短低上短高下；❌不能解释向上倾斜（仅当预期利率上升时倾斜，否则水平） |
| **市场分割理论** | 投资者极度风险厌恶；不同期限债券**完全不可替代**；资金完全不流动 | 长短期利率分别在各自市场独立形成；远期利率与预期短期利率**完全分割** | ❌不能解释同向波动；❌不能解释短低上短高下；✅可解释向上倾斜（长期债券需求相对更少，须更高利率） |
| **流动性溢价理论**（优先聚集地理论） | 投资者风险厌恶；不同期限债券**不完全替代**；资金不完全流动 | 长期利率 = 预期短期利率平均值 + **流动性溢价（LP）**：$y_n = \frac{\sum_{j=1}^{n}E(r_j)}{n} + LP_n$；远期利率 = 预期短期利率 + 流动性溢价：$f_n = E(r_n) + LP_n$；LP通常为正且随期限延长而增大 | ✅同向波动；✅短低上短高下；✅解释向上倾斜（即使预期利率不变，LP也使长期利率更高） |

> **流动性溢价理论是最符合现实的理论**——唯一同时解释三条经验法则的理论。收益率曲线向上倾斜不一定意味着预期利率上升（也可能只是LP的体现）；曲线向下倾斜**一定意味着**预期未来短期利率将大幅下降（足以抵消LP的影响）。

## 机制逻辑

**违约风险上升 → 利率上升的推导**：信用评级下调 → 市场对该债券违约风险评估上升 → 该债券吸引力下降 → 需求曲线左移 → 债券价格下跌 → 到期收益率（利率）上升；同时投资者增持国债（避险） → 国债需求曲线右移 → 国债价格上涨 → 国债利率下降。两债之间的**风险溢价**（利差）扩大。

**收益率曲线倒挂 → 经济衰退的传导逻辑**：市场参与者预期未来短期利率大幅下降（即预期央行将降息应对经济下行）→ 长期债券需求激增 → 长期利率下降 → 长短利差收窄甚至为负。历史上美债收益率曲线倒挂（10Y-3M为负）在多数衰退前6-18个月出现，被视为可靠预警信号。

**流动性溢价的影响因素**：持有期限越长 → 流动性越差 → 投资者要求更高补偿 → LP越大；此外，债券的市场流动性（买卖价差、市场冲击成本）直接影响LP水平。

## 比较辨析

| 经验法则 | 预期理论 | 市场分割理论 | 流动性溢价理论 |
|---------|---------|-----------|-----------|
| 各期限利率同向波动 | ✅（预期变动影响各期限） | ❌（各期市场独立） | ✅ |
| 短低上倾、短高下倾 | ✅（预期影响曲线斜率） | ❌ | ✅ |
| 曲线通常向上倾斜 | ❌（利率预期不变时水平） | ✅（长期市场利率偏高） | ✅（LP恒为正） |

| 理论对比 | 预期理论 vs 流动性溢价理论 |
|---------|--------------------------|
| 远期利率 | 预期理论：fn = E(rn) | 流动性溢价：fn = E(rn) + LPn |
| 长期利率 | 两者均：yn = 预期短期利率均值（+ LP） |
| 曲线斜率解释 | 预期理论：反映预期利率变化 | 流动性溢价：反映预期利率变化 + LP |

## 答案要点

**利率风险结构及主要种类（简答）**：
- 含义：具有相同到期期限的债券，因风险不同导致的利率差异
- 主要风险类型：
  - 违约风险（信用风险）：债务人无法按时足额偿还本息的可能性；信用评级越低、违约风险越高、须提供越高利率补偿
  - 流动性风险：债券难以迅速变现的可能性；变现成本（交易佣金、买卖价差、市场冲击）越高，利率越高
  - 税收风险：债券税收处理差异导致的实际收益率差异；免税债券可接受更低票面利率
  - 通货膨胀风险：通胀侵蚀债券实际购买力的可能性；非指数化债券须提供通胀风险溢价
  - 内嵌期权风险：可赎回、可转换等条款对投资者利益的影响

**收益率曲线（名词解释）**：
- 描绘期限不同的同类债券到期收益率与到期时间关系的曲线，横轴为到期时间，纵轴为到期收益率
- 典型形态：向上倾斜（正常，长期利率高于短期利率）、向下倾斜（倒挂，预示经济衰退）、水平、驼峰形
- 期限溢价（10年期国债利率 - 3月期国库券利率）是重要前瞻性经济景气指标

**利率期限结构三种理论的比较（论述）**：
- 预期理论：假设投资者风险中性，不同期限债券完全可替代；长期利率等于预期短期利率的算术平均值（fn = E(rn)）；能解释同向波动和短低上短高下，但不能解释曲线通常向上倾斜
- 市场分割理论：假设投资者极度风险厌恶，不同期限债券完全不可替代；长短期利率在各自市场独立决定；能解释向上倾斜，但不能解释同向波动
- 流动性溢价理论：假设投资者风险厌恶，不同期限债券不完全替代；长期利率 = 预期短期利率均值 + 流动性溢价（LP≥0且随期限递增，fn = E(rn) + LPn）；能同时解释三条经验法则，是最符合现实的理论
- 结论：流动性溢价理论最具解释力；收益率曲线向下倾斜一定意味着预期未来短期利率大幅下降（因为LP恒为正，只有预期利率大幅下降才能使曲线下倾）

**TED利差（名词解释）**：
- 三个月期欧洲美元同业拆借利率（LIBOR）与三个月期美国国库券利率之差
- 衡量银行间信用风险和金融市场压力的重要指标
- 经济危机时TED利差大幅上升（银行间不信任→LIBOR上升，同时资金涌入安全资产→国库券利率下降）；平稳期TED利差较低
