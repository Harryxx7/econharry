## 核心考点

**简答/论述必考**：三大动机的含义、影响因素及与利率的关系。**安全利率分析法**（从单个投资者到整个市场的推导）是论述题重点。**流动性陷阱**（货币需求对利率极度敏感，货币政策失效）是判断题固定考点。与费雪/剑桥的核心区别（货币需求不再是收入的固定比率）需掌握。

## 概念精讲

**基本定位**：微观视角，核心创新——引入**投机性货币需求**，强调利率在货币需求中的作用。货币需求不再是收入的固定比率，会随利率波动。

**核心公式**：

$$M_d = M_1 + M_2 = L_1(Y) + L_2(i) = L_{11}(Y) + L_{12}(Y) + L_2(i)$$

> 注：此处M1、M2是第一类/第二类货币需求，**不是**货币分层中的狭义/广义货币。

---

### 三种动机

**① 交易动机 → L₁₁(Y)**

- **产生原因**：收入和支出的时间不同步
  - 居民：月底发工资，但每天要花钱（所得动机）
  - 企业：先支出后收入（业务动机）
- 与收入Y**正相关**，与利率无关（凯恩斯原始假设）

**② 预防动机 → L₁₂(Y)**

- **产生原因**：支出的不确定性（意料之外的支出）
  - 居民：突然生病、随份子等；企业：原材料降价可多囤货等
- 与收入Y**正相关**，与利率无关
- **与交易动机的区别**：交易动机是计划之内，预防动机是意料之外

> 两者合并记为 L₁(Y)：都与Y正相关，都（按原假设）不受利率影响。

**除收入外的其他影响因素**：
- 收入获取时间间隔越长 → 货币需求越高
- 信用卡/花呗等支付方式出现 → 无需持币即可完成购买 → 货币需求下降

**③ 投机动机 → L₂(i)【凯恩斯真正的创新】**

- **产生原因**：在货币（无息）和债券（有息）之间做资产配置选择
- 与利率i**负相关**

**机会成本分析法**：
- 持有货币 = 放弃债券利息
- 利率↑ → 持币机会成本↑ → 减少持币 → L₂↓
- 利率↓ → 持币机会成本↓ → 增加持币 → L₂↑

---

### 安全利率分析法（引入预期）

**单个投资者逻辑**：每个投资者心中都有一个"安全利率"——认为正常的利率水平。
- 市场利率 < 安全利率 → 认为利率偏低未来会涨 → 债券价格未来会跌 → **持有货币**
- 市场利率 > 安全利率 → 认为利率偏高未来会降 → 债券价格未来会涨 → **持有债券**

**从单个投资者到整个市场**：
- 市场上投资者众多，每人的安全利率不同，服从正态分布
- 当前市场利率i₀左侧的投资者（安全利率低于i₀）→ 预期利率会降，债券价格会涨 → 持有债券
- i₀右侧的投资者（安全利率高于i₀）→ 预期利率会涨，债券价格会跌 → 持有货币
- 市场利率从i₀降到i₁：原本在i₀和i₁之间持有债券的投资者转向持货币
- **市场利率越低 → 转向持币的投资者越多 → 投机性货币需求越大**

> **两种分析法不矛盾，互相强化**：
> - 利率高时：直接利息损失大 + 预期未来利率下降债券价格上涨 → 减少持币
> - 利率低时：直接利息损失小 + 预期未来利率上升债券价格下跌 → 增加持币
> 
> 共同结论：**货币需求与利率负相关**。

### 完整货币需求函数

$$\frac{M_d}{P} = L_1(Y) + L_2(i) = L(Y, i)$$

- 货币需求与收入**正相关**，与利率**负相关**
- 利率永远用**名义利率**（债券收益率是名义概念）

**与货币流通速度的关系**：

$$V = \frac{PY}{M} = \frac{Y}{M/P} = \frac{Y}{L(Y, i)}$$

- 货币需求越少 → 同样产出需要更少货币 → 每块钱转得更快 → V越大
- 经济繁荣时 i↑ → L₂(i)↓ → 分母减小 → V↑（**顺周期**）

---

### 政策含义

- 流动性偏好理论是**LM曲线**的基础
- 货币政策传导：货币供给↑ → LM右移 → 利率↓ → 投资↑ → 产出和就业↑
- 支撑凯恩斯"**相机抉择**"政策主张（经济衰退→扩张性货币政策；经济繁荣→紧缩性）

**流动性陷阱**：利率降至零下限，货币需求对利率极度敏感（L₂趋于无穷），货币供给增加无法进一步压低利率 → **货币政策失效，财政政策有效**。

## 答案要点

**三大动机（简答）**：
- 交易动机：收入和支出时间不同步，与Y正相关
- 预防动机：支出不确定性（意外支出），与Y正相关（与交易动机区别：前者计划内，后者计划外）
- 投机动机（核心创新）：货币vs债券的资产配置，与利率i负相关（机会成本+安全利率预期分析，两者互相强化）

**安全利率分析法（论述）**：
- 每个投资者有一个主观"安全利率"；市场利率低于安全利率时持货币，高于时持债券
- 市场上安全利率服从正态分布；市场利率越低，转向持币的投资者越多
- 结论：投机性货币需求与利率负相关

**流动性陷阱（名词解释）**：
- 含义：利率降至极低水平，投资者普遍预期利率未来上升（债券价格会跌），货币需求对利率极度敏感，货币供给增加被完全吸收
- 结果：货币政策失效（LM水平），财政政策效力最强（无挤出效应）
