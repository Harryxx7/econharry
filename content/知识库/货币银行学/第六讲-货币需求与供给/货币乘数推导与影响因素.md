## 核心考点

**计算题必考**：狭义货币乘数 m₁ 的公式推导和各变量与乘数的关系（负相关规律）。分母越大→乘数越小的逻辑是选择题常考。各变量对货币乘数方向的影响（现金漏损率c上升→m₁↓）是判断题考点。

## 概念精讲

### 变量定义

| 符号 | 含义 |
|------|------|
| D | 活期存款 |
| T | 定期存款 |
| C | 流通中现金 |
| B | 基础货币（B = C + R） |
| R | 准备金（R = RR + ER） |
| **c = C/D** | 现金漏损率 |
| **$r_d$ = RR/D** | 活期存款法定准备金率 |
| **e = ER/D** | 超额准备金率 |
| **t = T/D** | 定期存款占活期存款的比例 |
| **$r_t$ = TR/T** | 定期存款法定准备金率 |

---

### 各类乘数公式

**① 活期存款乘数**：

$$\frac{D}{B} = \frac{1}{c + r_d + e + r_t t}$$

> 分母 = 所有"漏出去"的比例：
> - c：现金漏出
> - $r_d$：活期存款法定准备金留存
> - e：超额准备金留存
> - $r_t t$：定期存款准备金
> 
> 分母越大 → 乘数越小

**② 定期存款乘数**：

$$\frac{T}{B} = \frac{t}{c + r_d + e + r_t t} = \text{活期存款乘数} \times t$$

**③ 总存款乘数**：

$$\frac{D+T}{B} = \frac{1+t}{c + r_d + e + r_t t} = \text{活期存款乘数} \times (1+t)$$

**④ 狭义货币乘数 m₁（最重要）**：

$$m_1 = \frac{M_1}{B} = \frac{C+D}{B} = \frac{1+c}{c + r_d + e + r_t t}$$

- M₁ = C + D（现金 + 活期存款）
- 比活期存款乘数分子多了c，因为M₁包含现金

---

### 各变量与 m₁ 的关系

| 变量 | 方向 | 经济逻辑 |
|------|------|---------|
| $r_d$（活期法定准备金率）↑ | m₁ **↓** | 更多资金留存为准备金，减少放贷 |
| e（超额准备金率）↑ | m₁ **↓** | 银行主动多留准备金，减少放贷 |
| $r_t$（定期法定准备金率）↑ | m₁ **↓** | 定期存款资金被更多留存 |
| c（现金漏损率）↑ | m₁ **↓** | c虽同时在分子分母，但分母增加更多，净效果为乘数下降 |

> **规律**：凡是出现在分母里的变量，货币乘数与它们都是**负相关**的。
> 
> **经济逻辑**：任何变量上升都对银行贷款形成挤压 → 派生存款减少 → 货币供应量下降 → 货币乘数下降。

---

### 简单情形（无超额准备金，无现金漏损，无定期存款）

$$m_1 = \frac{1}{r_d}$$

例：$r_d$ = 20% → $m_1$ = 5

---

### 影响货币乘数的因素总结

**货币当局可控**：
- 法定准备金率 $r_d$、$r_t$（央行直接调整）
- 基础货币B（公开市场操作）

**商业银行可控**：
- 超额准备金率 e（银行持有超额准备金的意愿）

**公众可控**：
- 现金漏损率 c（公众持有现金vs存款的偏好）
- 定期存款比例 t（公众选择活期vs定期的偏好）

## 答案要点

**货币乘数公式（计算/简答）**：

$$m_1 = \frac{M_1}{B} = \frac{1+c}{c + r_d + e + r_t t}$$

- 分子1+c：M₁ = 现金（c倍活期）+ 活期存款
- 分母：所有漏出比例之和（现金漏损率+活期法定准备金率+超额准备金率+定期准备金占比）

**各变量影响（判断题）**：
- $r_d$↑、$r_t$↑、e↑、c↑ → 货币乘数**全部下降**（负相关）
- 规律：出现在分母里的变量与货币乘数负相关

**三类主体**：
- 央行控制：法定准备金率（最直接）
- 商业银行控制：超额准备金率（银行流动性意愿）
- 公众控制：现金漏损率c（持币偏好）和定期存款比例t
