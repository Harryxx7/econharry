## 核心考点

本讲是全科基础。货币职能（尤其流通手段与支付手段的区分）和格雷欣法则是选择题高频考点；货币制度演变（金本位三阶段、布雷顿森林体系内容与特里芬难题）是论述/简答高频考点；货币分层（M0/M1/M2构成）常以判断题出现。布雷顿森林体系、特里芬难题、格雷欣法则均为名词解释超高频词汇。

## 概念精讲

**货币的起源**：货币产生于物物交换的"双重巧合难题"——交易双方必须互为供求（光脚的理发师要找长发的鞋匠），交易成本极高。货币作为媒介，将物物交换拆成两步，大幅降低交易成本。

**货币的定义**（三种视角）：
- 马克思：从商品中分离出来、固定充当一般等价物的商品
- 西方主流：在商品支付中被普遍接受的任何东西（功能定义）
- 凯恩斯：货币是流动性——资产流动性（资产变成现实购买力而不受损失的能力）+ 负债流动性（金融机构以合理成本迅速筹集现金的能力）

**货币的形式演变**：实物货币 → 金属货币 → 纸币 → 存款货币 → 电子货币

> **纸币充当货币的条件**：①普遍接受性（靠国家信用背书）；②币值稳定性（纸币无自动蓄水池机制，依赖货币政策调控）。货币购买力 = 1/P（物价水平的倒数）。

> **金属货币的"自动蓄水池机制"**：黄金可自由铸造和熔化。货币数量多 → 金币熔化为商品金 → 货币数量↓ → 币值恢复；货币数量少 → 商品金铸造为金币 → 货币数量↑ → 币值恢复。纸币不具备此机制，故易引发通胀。

**货币的三大职能**：

| 职能 | 核心含义 | 典型场景 |
|------|---------|---------|
| 交易媒介 | 媒介商品交换，降低交易成本；分为流通手段和支付手段 | — |
| ↳ 流通手段 | "一手交钱，一手交货"，货与钱同时转移 | 日常购物 |
| ↳ 支付手段 | "赊买赊卖"，货币作为独立环节，补足前期交换 | 纳税、偿债、工资 |
| 价值尺度（记账单位） | 赋予交易对象以价格形态；货币单位是必要条件 | 定价标签 |
| 贮藏手段（资产职能） | 积累和保存价值，优化消费跨期配置 | 储蓄、持有资产 |

注：交易媒介和价值尺度解决"双重选择难题"；贮藏手段优化消费跨期配置。

**货币制度的基本内容**：政府对一系列货币问题的安排，包括：①币材；②货币单位（主币/辅币）；③货币的法偿能力（无限法偿：无论金额大小对方不得拒绝；有限法偿：支付规模存在阈值）；④铸造、发行和流通程序；⑤发行准备制度（现金准备+票券准备）。

> **铸币税**：政府垄断货币发行权所获取的收入。金属本位制 = 铸币面值 - 铸造成本；纸币本位制 = 纸币面值（购买力）- 发行成本；双层次创造机制 = 央行资产方利息收入 - 负债方利息支出。

**国家货币制度的历史演变**：

- **银本位制**（16世纪）
- **金银复本位制**（16-18世纪）：金、银两种铸币均有无限法偿能力，可自由兑换。演变：平行本位制（政府不限制金银比价）→ 双本位制（政府限制金银比价，产生格雷欣法则）→ 跛行本位制（金可自由铸造、银不能）
- **金本位制**（19世纪）：金币本位制 → 金块本位制 → 金汇兑本位制（趋势：兑换黄金越来越难，根源是黄金供给不足以支撑全球经济扩张）
- **纸币本位制**（20世纪至今）：兑现纸币和不兑现纸币

> **格雷欣法则（劣币驱逐良币）**：背景为双本位制——政府规定金银官方比价（如1金=5银），而市场比价为1金=10银。良币（金）被低估（官价<市价）→ 理性人将金贮藏/熔化/输出国境，用被高估的银（劣币）支付 → 银充斥流通，金退出市场。良币行使贮藏手段职能。

> **金本位制三阶段**：①金币本位制（"四个自由"：自由铸造、自由熔化、自由兑换、自由输出入国境）；②金块本位制（银行券须达到一定金额才能兑换黄金金块）；③金汇兑本位制（先将本国银行券换成外汇，再拿外汇去外国换黄金）。

**国际货币制度演变**：国际金本位制（1880s-1944）→ 布雷顿森林体系（1944-1972）→ 牙买加体系（1976-）

> **布雷顿森林体系**（双挂钩，1944年建立）：①美元与黄金挂钩（35美元兑1盎司黄金）；②其他货币与美元挂钩，实行可调整的钉住汇率制——均衡汇率（含金量）一般不变，市场汇率在±1%内波动，超过10%调整须IMF批准。

> **特里芬难题**：布雷顿森林体系的内在矛盾。国际贸易扩大 → 对美元需求增加 → 美国须维持国际收支逆差方能供给足够美元 → 逆差积累导致美元信心受损，无法维持与黄金固定兑换比率；若美国维持顺差 → 美元供给不足 → 全球清偿力不足。信心与清偿力不可兼得，体系必然崩溃（1972年）。

> **牙买加体系**（1976年生效）：三个核心特点——①黄金非货币化（彻底退出货币舞台）；②国际储备多元化；③汇率制度多样化（以浮动汇率为主，固定汇率并存）。

**货币分层**（依据：流动性）：

| 层次 | 构成 | 备注 |
|------|------|------|
| M0 | 流通于银行体系以外的现金（含数字人民币） | 商业银行库存现金和准备金**不是**货币 |
| M1（狭义货币） | M0 + 单位活期存款 + 个人活期存款 + 非银行支付机构客户备付金 | 现实购买力 |
| M2（广义货币） | M1 + 单位/个人定期存款 + 其他存款 + 非存款类金融机构货币市场基金 | QM（准货币）= M2 - M1，为潜在购买力 |

M1/M2比值↑ → 货币供给流动性↑ → 可能意味着经济趋热。

## 机制逻辑

**格雷欣法则的推导**：双本位制下，政府规定官价1金=5银，市场价1金=10银。持有金更合算（市场价高于官价）→ 理性人将金贮藏/熔化/出口，用银支付 → 银充斥流通领域，金退出。核心逻辑：价格被扭曲时，理性人套利会导致"好的"退出、"差的"留下。

**金本位走向纸币本位的逻辑**：全球经济规模扩大，对货币需求持续增长，但黄金供给增速远不及需求 → 兑换黄金条件逐步收紧（金币→金块→金汇兑）→ 最终完全脱钩 → 纸币本位制。根本矛盾：实物货币供给弹性不足。

**布雷顿森林体系崩溃的推演**：二战后美国经济相对衰落 → 贸易逆差扩大 → 美元流向世界 → 各国美元储备积累 → 对美国黄金储备的信心下降 → 各国纷纷将美元兑换黄金（尤其法国）→ 美国黄金储备迅速耗尽 → 1971年尼克松宣布美元停止兑换黄金 → 布雷顿森林体系实际崩溃。

## 比较辨析

| 对比项 | 流通手段 | 支付手段 |
|--------|---------|---------|
| 时序 | 一手交钱一手交货，同时发生 | 先交货后付款（或先付款后提货），货币独立清偿 |
| 典型场景 | 日常购物、零售交易 | 纳税、偿还债务、支付工资 |
| 是否存在信用 | 否（即时结清） | 是（存在时间差） |

| 对比项 | 金币本位制 | 金块本位制 | 金汇兑本位制 |
|--------|-----------|-----------|------------|
| 黄金兑换 | 自由兑换，无限制（"四个自由"） | 须达到一定金额才能换金块 | 先换外汇，再去外国换黄金 |
| 黄金流动 | 自由输出入国境 | 受限 | 最受限 |
| 历史时期 | 19世纪鼎盛期 | 一战后 | 两战之间 |

| 对比项 | 布雷顿森林体系 | 牙买加体系 |
|--------|--------------|---------|
| 汇率制度 | 可调整的钉住汇率（以美元为中心） | 以浮动汇率为主、多种制度并存 |
| 黄金地位 | 美元与黄金挂钩，黄金仍是国际储备核心 | 黄金非货币化，退出货币舞台 |
| 国际储备 | 美元为主 | 多元化（美元、欧元、特别提款权等） |

## 答案要点

**货币的职能（简答/名词解释）**：
- 货币具有三大职能：交易媒介（含流通手段和支付手段）、价值尺度、贮藏手段
- 流通手段：一手交钱一手交货，货币媒介商品交换，货与钱同时转移
- 支付手段：货币作为独立环节清偿已发生的债务关系，如纳税、偿债、支付工资；应用于大宗交易、银行信用等场景
- 价值尺度（记账单位）：赋予交易对象以价格形态；货币单位是发挥该职能的必要条件
- 贮藏手段：货币退出流通，积累和保存价值，优化消费跨期配置

**格雷欣法则（名词解释）**：
- 背景：双本位制下政府规定金银官方比价（价格扭曲）
- 含义：劣币驱逐良币——实际价值被高估的货币（官价>市价，即劣币）充斥流通，实际价值被低估的货币（官价<市价，即良币）退出流通
- 机制：良币实际价值高于官价 → 理性人将良币贮藏/熔化/输出国境，以劣币支付 → 良币退出、劣币充斥
- 良币在此过程中行使的是贮藏手段职能

**货币制度的基本内容（简答）**：
- 定义：政府对一系列货币问题的制度安排，目的在于稳定货币体系、保证货币职能的发挥
- 五大内容：①币材（金属货币时代为核心要素）；②货币单位；③货币法偿能力（无限法偿与有限法偿的区别）；④货币铸造、发行和流通程序（含铸币税）；⑤发行准备制度（现金准备+票券准备）

**布雷顿森林体系（名词解释/简答）**：
- 建立：1944年，以美国怀特计划为基础建立，IMF为核心机构
- 核心内容（双挂钩）：①美元与黄金挂钩——35美元兑换1盎司黄金；②其他货币与美元挂钩——实行可调整的钉住汇率制，市场汇率在均衡汇率±1%内波动，调整超过10%须经IMF批准
- 崩溃：特里芬难题导致的内在不稳定，1972年正式崩溃

**特里芬难题（名词解释）**：
- 含义：布雷顿森林体系下美元供给与黄金信心之间的内在矛盾
- 两难：①若美国维持国际收支顺差，美元供给不足，全球清偿力匮乏；②若美国维持逆差以供给美元，逆差积累导致美元与黄金固定兑换比率的可信度下降
- 结果：两者不可兼得，体系存在内在不稳定性，必然崩溃

**货币分层（M0/M1/M2）**：
- 分层依据：流动性（流动性越高越接近货币本质）
- M0 = 流通于银行体系以外的现金（含数字人民币）；商业银行库存现金和各类准备金不计入货币
- M1（狭义货币，现实购买力）= M0 + 单位活期存款 + 个人活期存款 + 非银行支付机构客户备付金
- M2（广义货币）= M1 + 单位/个人定期存款 + 其他存款 + 非存款类金融机构货币市场基金
- QM（准货币）= M2 - M1，为潜在购买力；M1/M2比值上升反映货币流动性偏高
