## 核心考点

金融市场分类是选择/判断高频考点，尤其**直接融资与间接融资的本质区别**（资金所有权是否转移、是否存在金融中介）以及**货币市场与资本市场的划分标准**（以1年为界）反复出现。货币市场各工具（国库券、商业票据、NCD、同业拆借、回购协议）常以"属于哪类市场"出题；金融市场功能（积聚、配置、信号、流动性、风险转移）偶以简答考查。

## 概念精讲

**金融市场的含义**：资金供求双方进行金融资产（货币、有价证券、外汇等）交易的场所。构成要素：①交易对象（金融资产）；②交易主体（资金供求双方、金融中介）；③交易价格（利率、汇率、证券价格）；④交易场所（有形或无形）。

**直接融资与间接融资**：

| 对比项 | 直接融资 | 间接融资 |
|--------|---------|---------|
| 是否经过金融中介 | 否，资金需求方直接面向社会 | 是，由银行等金融中介撮合 |
| 资金所有权 | 资金供给方（投资者）保留最终索偿权 | 资金所有权暂时转移给中介，中介承担风险 |
| 典型工具 | 股票、债券（发行方直接向公众募资） | 银行存款/贷款 |
| 风险承担 | 供给方自担风险 | 中介承担信用风险（吸收存款+发放贷款） |

> **核心辨析**：股票和债券均属直接融资工具，但通过证券公司承销仍是直接融资——金融中介只是"通道"而非资金所有者。银行贷款属间接融资，银行自身承担信用风险。

**金融市场的分类**（四大维度）：

| 分类维度 | 子市场 | 核心特点 |
|---------|-------|---------|
| 交易对象期限 | **货币市场**（≤1年） | 短期、低风险、高流动性；工具：国库券、商业票据、NCD、同业拆借、回购协议 |
| | **资本市场**（>1年） | 期限长、收益高、风险大；工具：股票、长期债券 |
| 发行/流通阶段 | **初级市场**（发行市场） | 证券首次发行，为筹资者融资 |
| | **二级市场**（流通市场） | 已发行证券的转让买卖，为投资者提供流动性，决定证券价格 |
| 交割时效 | **即期市场** | 成交后立即（或短期内）交割 |
| | **远期/衍生品市场** | 约定未来某一日期按今日价格交割，用于对冲风险或投机 |
| 交易场所 | **交易所市场** | 集中、有组织、公开竞价，如上交所 |
| | **场外市场（OTC）** | 分散、双边协商定价，如银行间债券市场 |

**货币市场主要工具**：

| 工具 | 含义 | 特点 |
|------|------|------|
| 国库券（T-bill） | 政府发行的短期（≤1年）债务凭证 | 流动性最强，几乎无违约风险，基准利率 |
| 商业票据 | 大型企业发行的短期无担保本票 | 用于临时融资，信用等级要求高 |
| 银行承兑汇票 | 银行承诺到期付款的汇票 | 流动性强，可贴现；承兑行信用背书 |
| 大额可转让存单（NCD） | 银行发行的固定期限、可转让的定期存单 | 可在二级市场流通，面值较大 |
| 同业拆借 | 金融机构之间的短期（通常隔夜至1年）资金借贷 | 利率反映银行体系资金松紧（SHIBOR） |
| 回购协议（Repo） | 卖出证券同时约定未来买回 | 正回购=融资方，逆回购=资金方；央行逆回购=向市场投放资金 |

**金融市场的五大功能**：
1. **积聚功能**：汇集分散的小额储蓄形成大额资本
2. **资源配置功能**：将资金引导至效率最高的投资用途
3. **信号功能**：市场价格（利率、股价）传递资金供求信息
4. **提高流动性**：二级市场使长期金融资产可以随时变现
5. **风险转移与分散**：衍生品和多元化投资分散和转移风险

## 机制逻辑

**二级市场对初级市场的支撑**：初级市场能否顺利融资，取决于投资者对未来流动性的信心。没有发达的二级市场，投资者担心"买了卖不出去"，会压低出价甚至不买——因此二级市场的流动性是初级市场融资效率的前提。

**货币市场利率作为"价格信号"**：同业拆借利率（SHIBOR、联邦基金利率）反映整个银行体系的资金紧张程度，央行通过公开市场操作（逆回购/正回购）调控这一利率，进而影响整个社会资金成本。

## 比较辨析

| 对比项 | 货币市场 | 资本市场 |
|--------|---------|---------|
| 期限标准 | ≤1年 | >1年 |
| 风险程度 | 低 | 高 |
| 流动性 | 高 | 相对低（股票例外） |
| 典型工具 | 国库券、商业票据、同业拆借 | 股票、公司债、国债（长期） |
| 主要功能 | 短期资金融通、维持流动性 | 长期资本形成、资产定价 |

| 对比项 | 直接融资 | 间接融资 |
|--------|---------|---------|
| 媒介 | 无金融中介（或中介只是通道） | 有金融中介居间 |
| 典型工具 | 股票、债券 | 银行贷款、存款 |
| 信息对称性 | 要求高（信息披露义务） | 由中介承担信息搜集和审核 |
| 风险转移 | 风险留在投资者手中 | 银行等中介吸收风险 |

## 答案要点

**直接融资与间接融资的区别（简答）**：
- 直接融资：资金需求者直接向资金供给者发行金融工具（股票、债券）筹资，资金供给者直接持有最终借款者的债权/股权，自担风险；典型如企业发行债券、股票IPO
- 间接融资：通过银行等金融中介媒介，中介吸收资金供给者存款，再贷款给资金需求者；中介自身承担信用风险，存款人持有的是对中介的债权而非最终借款者的债权
- 核心区别：是否经过金融中介"资产转换"（中介将存款负债转化为贷款资产，完成期限转换、风险分担和信息生产）

**货币市场工具的简答**：
- 国库券：政府发行，期限≤1年，流动性最强，违约风险极低，是基准无风险利率
- 商业票据：大型企业发行，无担保，期限短，须信用评级
- 银行承兑汇票：商业票据经银行承兑，信用提升，可在货币市场流通、贴现
- 大额可转让存单：银行发行，固定期限，可在二级市场转让，面值大
- 同业拆借：银行间短期资金借贷，隔夜至数月，利率（SHIBOR）是货币市场基准
- 回购协议：以证券为抵押的短期融资，央行逆回购 = 向市场注入流动性

**金融市场分类（简答要点）**：
- 按期限：货币市场（≤1年）vs 资本市场（>1年），是最基本的分类维度
- 按发行阶段：初级市场（新发行，融资功能）vs 二级市场（流通转让，流动性功能）
- 按交割时效：即期市场 vs 远期/衍生品市场（期货、期权、互换）
- 按交易场所：交易所市场（集中竞价、透明）vs 场外市场（分散、双边协商）
