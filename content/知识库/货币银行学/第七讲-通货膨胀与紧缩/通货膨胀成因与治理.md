## 核心考点

**名词解释高频**：需求拉动型/成本推进型/结构性通货膨胀三者含义与区别（多所院校考过）；菲利普斯曲线（短期负相关、长期垂直，2020中南财/2022人大）是论述热点。**简答题**：通货膨胀的成因分类（三分法）；通货膨胀的经济效应（正负两面，收入再分配/Mundell-Tobin/增长效应）；治理措施（需求管理+供给管理+收入政策三层次）。**计算题**：CPI计算和通胀率计算（结合具体数字）。

## 概念精讲

**通货膨胀的含义**：一般价格水平的**持续**上升，或等价地说，货币购买力的持续下降。三个要素：①价格指标是**总价格水平**（单个商品涨价不算）；②**持续性**（一次性价格调整不算）；③货币现象（弗里德曼："通货膨胀无论何时何地都是一种货币现象"）。

**通货膨胀的度量**：

| 指标 | 含义 | 特点 |
|------|------|------|
| **消费者价格指数（CPI）** | 固定消费品篮子的价格变动 | 最常用，月度公布；可能高估（替代效应）；反映城镇居民生活成本 |
| **GDP平减指数** | 名义GDP与实际GDP之比，覆盖所有国内最终产品 | 更全面（含投资品、政府购买）；高估问题较小；季度公布 |
| **生产者价格指数（PPI）** | 生产环节价格变动 | 领先指标，PPI上行往往预示CPI上行 |

> **CPI高估问题**：CPI使用固定篮子，当商品相对价格变动时，消费者会替代昂贵商品（替代效应），使实际生活成本上升幅度低于CPI涨幅；此外，CPI难以捕捉新产品引入和质量改进带来的福利提升——这导致CPI可能系统性高估真实通货膨胀约0.5-1.5个百分点（Boskin委员会估计）。

**通货膨胀成因三分法**：

**① 需求拉动型通货膨胀（Demand-Pull Inflation）**

> 过多的货币追逐过少的商品——由总需求超过总供给引起的价格上升。

- **货币数量论视角**：MV = PT，若货币供给M扩张（V稳定），P必然上升
- **AD-AS框架**：总需求（AD）曲线右移，在短期总供给（AS）不变时，均衡价格上升
- **触发因素**：货币供给过度扩张（中央银行超额印钞）、财政赤字货币化（政府向央行透支）、投资需求过热（信贷扩张）、出口骤增（外需大幅拉动）
- **特征**：伴随产出和就业上升（短期），表现为"通胀高/就业好"并行

**② 成本推进型通货膨胀（Cost-Push Inflation）**

> 生产成本上升导致总供给减少，在总需求不变时推动价格上升（AS左移）。

分为三个子类：

| 子类 | 含义 | 典型案例 |
|------|------|---------|
| **工资推动型** | 工资增长超过劳动生产率增长，企业将成本转嫁给消费者 | 强势工会集体谈判、最低工资大幅提升 |
| **利润推动型** | 垄断企业凭市场势力提高利润加成定价（Mark-up Pricing） | 石油输出国提高油价（1973年石油危机） |
| **输入型通胀** | 进口原材料/能源价格上涨传导至国内成本 | 大宗商品价格上涨（铁矿石、原油） |

- **特征**：伴随产出下降和失业上升（"滞胀"，Stagflation）——与需求拉动型相反，更难治理

**③ 结构性通货膨胀（Structural Inflation）**

> 由经济结构失调引起的通货膨胀，即便总需求未超过总供给，也会出现价格上升。

- **机制**：不同部门生产率增长速度不同（如制造业生产率高、服务业低），但工资趋向均等化（Baumol病）；服务业为保持相对工资，不得不提高服务价格，拉动总价格水平上涨
- **另一机制**：劳动力和资本无法在部门间自由流动——高需求部门价格上涨，低需求部门价格却难以下降（价格粘性的不对称性）
- **典型现象**：新兴经济体工业化过程中的结构性通胀；城镇化推动房价上涨即带有结构性成分

**菲利普斯曲线（Phillips Curve）**

1958年，英国经济学家菲利普斯发现英国1861-1957年间工资增长率与失业率之间存在稳定负相关关系；后被推广为**通货膨胀率与失业率**之间的负相关关系。

**短期菲利普斯曲线**：

$$\pi = \pi^e - \beta(u - u^*)$$

其中 $\pi$ = 实际通胀率，$\pi^e$ = 预期通胀率，$u$ = 实际失业率，$u^*$ = 自然失业率（NAIRU），$\beta > 0$。

- 短期内，失业率低于自然失业率（u < u*）→ 通胀上升；失业率高于自然失业率（u > u*）→ 通胀下降
- 提供了需求管理政策的操作空间：牺牲一定通胀换取就业，或反之

> **自然失业率（Natural Rate of Unemployment / NAIRU）**：在没有意外通胀/通缩冲击时经济长期趋向的失业率，包含摩擦性失业和结构性失业，不包含周期性失业。当实际失业率等于自然失业率时，产出处于潜在水平，通胀稳定（既不加速也不减速）。弗里德曼认为自然失业率由供给侧因素决定，政策无法长期改变。

**长期菲利普斯曲线（垂直）**：

长期中，预期通胀等于实际通胀（$\pi^e = \pi$），则 $u = u^*$——无论通胀率多高，失业率都回到自然失业率，曲线变为一条垂直线（Friedman-Phelps加速通胀假说）。

> **政策含义**：政府试图通过扩张需求将失业率长期维持在自然失业率以下，结果只会导致通胀不断加速（加速通胀），最终失业率仍回到 u*。货币政策在短期有实际效果，长期无效（货币中性）。

**通货膨胀的经济效应**：

**① 收入与财富再分配效应**：
- 债务人受益（实际债务缩水）、债权人受损（持有固定名义索取权的人，如持有固定利率债券者）
- 实物资产持有者受益（房产、股票随通胀升值）、货币持有者受损（现金购买力下降）
- 固定名义收入者受损（退休人员、公务员），浮动收入者影响不确定

**② Mundell-Tobin效应（通胀促增长？）**：
- 通胀↑ → 持有货币的机会成本↑ → 人们减少货币持有，增加实物资产投资（资本积累↑） → 资本存量↑ → 产出↑（短期正效应）
- **反驳**：该效应忽略了通胀不确定性对投资决策的负面干扰，以及"鞋底成本"（跑银行次数增加）和"菜单成本"（频繁更新价格）

**③ 通胀与经济增长的关系（争议）**：
- **温和通胀有益论**（托宾等）：低通胀（2-3%）可降低实际工资刚性，使劳动力市场调整更顺畅；Mundell-Tobin效应促进资本积累
- **通胀有害论**（弗里德曼等）：高通胀和通胀不确定性扭曲价格信号，损害资源配置效率；超过10%后通胀与增长显著负相关
- **现实共识**：适度低通胀（各国央行目标约2%）有利于经济运行；高通胀尤其恶性通胀严重损害经济

**通货膨胀的治理措施**：

**① 需求管理政策（治理需求拉动型为主）**：
- **紧缩性货币政策**：提高利率、减少货币供给（提高法定准备金率、公开市场卖出、提高再贴现率）→ 压缩信用需求 → AD左移
- **紧缩性财政政策**：增税减支，压缩财政赤字 → 减少政府支出 → AD左移
- **代价**："反通胀的痛苦指数"——紧缩需求同时也压缩产出，导致失业上升（短期菲利普斯曲线的权衡）

**② 供给管理政策（针对成本推进型）**：
- 减税、补贴、技术进步政策扩大总供给（AS右移）
- 降低生产成本：放松市场管制、提高竞争、打破垄断
- 供给侧改革（如1980年代里根经济学）：减税+放松管制

**③ 收入政策（Incomes Policy）**：
- 直接限制工资和价格增长速度（工资-价格管制）
- 自愿性收入准则（工资增长不超过生产率增长）
- 指数化政策（工资/合同按CPI自动调整，减少通胀不确定性的伤害）
- **局限性**：价格管制扭曲资源配置，难以持久；行政成本高

## 机制逻辑

**需求拉动 vs 成本推进的 AD-AS 机制对比**：
- 需求拉动：AD右移 → 价格↑ + 产出↑（短期）→ 工资随之上升（AS左移）→ 价格进一步上升，产出回落（长期）
- 成本推进：AS左移 → 价格↑ + 产出↓（滞胀）→ 如央行被动扩张货币维持就业 → AD右移 → 价格进一步上升 → 工资-价格螺旋

**工资-价格螺旋（Wage-Price Spiral）**：成本推进型通胀的核心传导机制。企业成本上升 → 价格上涨 → 工人要求涨工资维持购买力 → 工资上涨进一步推高成本 → 再次涨价……形成自我强化循环。打破此螺旋需要货币当局坚定反通胀承诺（央行可信度的重要性）。

**长期菲利普斯曲线垂直的机制**：短期，政府扩张需求 → 失业率↓（u < u*）→ 通胀上升 → 但工人调整预期，要求提高工资补偿通胀 → 实际工资恢复 → 企业减少雇佣 → 失业率回到 u* → 短期菲利普斯曲线向上平移（预期通胀上升）→ 长期结果：只有通胀上升，就业不变。

**治理通胀的代价——牺牲率（Sacrifice Ratio）**：将通胀率永久降低1个百分点所需牺牲的GDP百分点数。牺牲率越高，反通胀代价越大。央行的可信度（Credibility）越高（公众相信央行会坚持反通胀），预期通胀下调越快，牺牲率越低（无成本反通胀的理论极限）。

## 答案要点

**通货膨胀的成因（简答）**：
- **需求拉动型**：总需求超过潜在总供给引起价格上升；根源是过度的货币供给扩张或财政赤字货币化；特征是产出和就业短期上升（景气通胀）；货币数量论框架下，M↑→P↑
- **成本推进型**：生产成本上升导致总供给减少推动价格上涨；分为工资推动（工资增长超过生产率增长）、利润推动（垄断提价）、输入型（进口原材料涨价）；特征是产出下降、失业上升，即"滞胀"
- **结构性通胀**：由经济结构失调引起，即使总需求不过剩也会发生；典型机制是不同部门生产率增速差异（Baumol病）或劳动力无法在部门间自由流动，导致价格单方向上涨
- 三类成因并非互斥，现实中通常相互交织

**菲利普斯曲线（简答）**：
- **含义**：描述通货膨胀率与失业率之间关系的曲线，最初由菲利普斯根据英国1861-1957年数据发现工资增长率与失业率存在稳定负相关
- **短期**：呈负斜率——当失业率低于自然失业率时，通胀上升；反之下降；为货币政策的通胀-失业权衡提供依据
- **长期（弗里德曼-菲尔普斯）**：预期充分调整后，通胀率高低不影响实际失业率，曲线垂直于自然失业率水平——货币政策长期无效（货币中性），试图将失业率长期维持于自然失业率以下只会导致通胀不断加速
- **政策含义**：短期可通过需求扩张降低失业，但代价是更高通胀；长期需接受自然失业率，货币政策目标应锁定价格稳定

**通货膨胀的治理措施（简答）**：
- **需求管理政策**：紧缩货币政策（提高利率、减少货币供给）和紧缩财政政策（增税减支）压缩总需求，使AD左移；主要针对需求拉动型通胀；代价是产出下降和失业上升（牺牲率）
- **供给管理政策**：减税、放松管制、鼓励技术进步等扩大总供给（AS右移）；主要针对成本推进型通胀；无牺牲率问题，但见效慢
- **收入政策**：直接限制工资和价格增长速度（工资-价格管制或自愿准则）；打断工资-价格螺旋；可指数化合同降低通胀不确定性的伤害；局限是扭曲资源配置，难以持久

**通货膨胀效应（简答）**：
- **收入与财富再分配**：通胀使实际债务缩水——债务人受益、债权人受损；持有实物资产者受益、持有货币和固定名义资产者受损；固定名义收入者（退休人员）购买力下降
- **Mundell-Tobin效应**：通胀上升使货币持有机会成本升高，人们将资金从货币转向实物投资，资本积累加快，短期可能促进增长（温和通胀有益论的依据）
- **总体判断**：温和通胀（约2%）一般无显著危害；高通胀和通胀不确定性严重扭曲价格信号，损害资源配置和投资决策，与经济增长负相关
