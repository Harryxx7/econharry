## 问题

永续年金、永续增长年金、T年普通年金、T年增长年金的现值与终值公式？

## 答案

### 二、折现现金流量估价

#### 1. 永续年金

$$PV = \frac{C}{r}$$

#### 2. 永续增长年金

$$PV = \frac{C}{r - g}$$

#### 3. T 年普通年金

$$PV = C + \frac{C}{1+r} + \frac{C}{(1+r)^2} + \cdots + \frac{C}{(1+r)^T} = C \times \left(\frac{1}{r} - \frac{1}{r(1+r)^T}\right)$$

$$PV = C \times \frac{1 - \dfrac{1}{(1+r)^T}}{r}$$

#### 4. T 年普通年金的终值公式

$$FV = C \times \frac{(1+r)^T - 1}{r}$$

#### 5. T 年增长年金

$$PV = \frac{C}{1+r} + \frac{C \times (1+g)}{(1+r)^2} + \cdots + \frac{C \times (1+g)^{T-1}}{(1+r)^T} = \frac{C}{r-g} \times \left[1 - \left(\frac{1+g}{1+r}\right)^T\right]$$

#### 6. T 年增长年金的终值

$$FV = C \times (1+r)^{T-1} + \cdots + \frac{C \times (1+g)^{T-1}}{(1+r)^T} = \frac{C}{r-g} \times \left[(1+r)^T - (1+g)^T\right]$$
