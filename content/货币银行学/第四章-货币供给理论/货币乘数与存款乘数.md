## 问题
狭义货币乘数 $m_1$ 和广义货币乘数 $m_2$ 如何推导？存款乘数怎么算？

## 答案

### 基础货币与货币供给

$$M_S = B \times m \Rightarrow B = \frac{M_S}{m}$$

基础货币 $B$ = 货币供应量 / 货币乘数

---

### 1. 货币乘数

设 $c = C/D$（通货存款比），$rr = RR/D$（法定准备金率），$er = ER/D$（超额准备金率），$t = T/D$（定期存款比）

**(1) 狭义货币乘数 $m_1$**（对应 M1 = C + D）

$$m_1 = \frac{M_1}{B} = \frac{C+D}{C+R} = \frac{\frac{C}{D}+1}{\frac{C}{D}+\frac{RR}{D}+\frac{ER}{D}+\frac{TR}{D}} = \frac{1+c}{c+rr+er+tr}$$

**(2) 广义货币乘数 $m_2$**（对应 M2 = C + D + T）

$$m_2 = \frac{M_2}{B} = \frac{C+D+T}{C+R} = \frac{1+c+t}{c+rr_d+er+tr_t}$$

---

### 2. 存款乘数

**(1) 活期存款乘数**

$$\text{活期存款乘数} = \frac{D}{B} = \frac{1}{C+RR+ER+TR} = \frac{1}{c+rr+er+tr}$$

**(2) 定期存款乘数**

$$\text{定期存款乘数} = T\text{（定期存款）}/B\text{（原始存款）} = \frac{c+r_d+e+tr_t}{t}$$

**(3) 总存款乘数**

$$\text{总存款乘数} = (D/B) + (T/B) = \frac{(D+T)}{B} = \frac{1+t}{c+r_d+e+tr_t}$$

## 考点提示
> 货币乘数与基础货币是货币供给分析的核心框架。记住分子是"货币量"，分母是"基础货币的构成"。$m_1$ 的分子分母都除以 D 来推导是常见考法，务必熟练推导。
